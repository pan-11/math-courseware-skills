# 课件小红书笔记制作

把已完成的课件及真实配套资料转成老师能看懂的一组笔记。独立于整课制作流程；不要求重做原课、运行十二模块或调用任何 `k12-courseware-*` Skill。

图文和视频笔记的封面默认采用鹿鸣已确认的**故事海报**：大课名、满版3D故事画面、突出角色，各篇按主题改变构图，详见[封面制作要求](references/visual-production.md)。沿本课已采用人物与画风；用户当次指定的其他风格优先。内容页的排版分配不替代这一封面要求，已确认的方向直接沿用，不增加逐篇审批。

## 判断本次范围

- “想方案、选题、设计稿”：只交可审阅规划，不把规划说成成品。
- “制作一篇/修改某张”：只处理指定篇或图片，沿用已核来源与风格。
- “制作一组/这门课的笔记素材”：默认每门课交3篇图文＋2篇视频剪辑资料包。图文第1篇用本地排版1，第2篇由AI按内容从排版2/3/4中选一种，第3篇沿用原来的讲解/对照/配套图文样式；详见[整组分配与选版](references/note-planning.md)。这是三篇独立图文，各自一套素材；封面按原有规则制作，视频按原流程准备。用户另有数量、形式要求时按当次要求；素材不足时说明缺口，不静默减篇或把不完整包称为完成。
- 首版视频产物为**剪辑资料包**：实际封面、标题正文、可执行剪辑清单、选用素材及必要口播稿。用户自行剪辑；没有真实 MP4 成片就不写“视频已完成”。

## 生产顺序

文件位置遵循[每课四目录规范](../math-courseware-studio/references/workspace-layout.md)：沿用户已给定课程根读取03_final当前有效产品；笔记策划、排版与核查过程放02_work/notes，实际按篇交付包放04_notes/vNNN/note-NN，README注明当前版本与待剪辑状态。旧课复用其真实交付位置，不自动搬动；独立笔记任务不要求重跑或补造整课状态。

1. 先读工作目录 `AGENTS.md`、`HANDOFF.md` 及课程交接；检查现存文件和未提交改动。按[选题与来源](references/note-planning.md)核定当前 PPT、视频、教学设计、逐字稿、说课稿、学习单、黑板贴及已有宣传图。只使用已存在且能核对的文件；历史截图和修改时间不能单独决定采用版本。发现教材版本、页码、数学或视频画面冲突时先处理证据，不把冲突带入宣传图。
2. 为每篇写一句老师关心的问题，列独有证据、形式、图序或剪辑路径、交付文件。对照整组检查主题是否重复。用户已给具体设计方案时沿用，必要调整写明来源原因，不机械套固定的五主题。
3. 依据[图文制作](references/visual-production.md)完成可用封面与内容图；整组图文前两篇的课件主体按既定分配调用[本地排版工具](references/local-layout-tool.md)，显式传入模板、本课选页顺序、参数和全新工作目录，保存真实渲染来源，第2篇记录选版理由。第3篇使用原`dual/focus/companion`说明卡。每篇默认配1张与主题相关的配套内容卡，最多1张：图文1教学设计片段、图文2逐字稿片段、图文3电子黑板贴使用示意；可按选题与实际资料调换，没有对应成品或不相关时记录原因、不硬加。配套卡紧跟相关课件图，第3篇优先融入原`companion`组合卡，按[交付格式](references/copy-and-review.md)标记来源，不替代前两篇主体版式。单篇按其实际选题与用户指定版式。依据[视频剪辑资料](references/video-production.md)完成两篇视频包。真实课件页、尺图、数字和文稿局部用实际来源等比排版，不用生图重画事实内容。艺术封面按用户指定图像路线制作并目视核对；已有合适成品直接复用。
4. 按[文案与交付检查](references/copy-and-review.md)给每篇一条主标题和完整正文，核事实、数学、来源、手机缩图及文件可用性。可运行 `scripts/check_delivery.py` 做机械检查；它不能替代逐图目视、逐句读稿和视频实际看听。

## 交付边界

图文篇交实际封面、按序内容图、标题正文：四种本地排版均为带渲染清单的原版式JPG，原解释卡为PNG；视频篇交实际封面、标题正文、剪辑清单、选用素材路径和必要口播文稿。默认整组在delivery.json标记`series_profile: "three-image-two-video"`并检查3图文/2视频及三类图文分配。内部来源/提示词/测试留在工作区，成品按篇放清楚。完成当轮主动在聊天展示实际图、编号文件名、图序及整包目录。若已有符合主题的图，复用并记录来源，不无故再生。没有独立“讲课稿”时，从逐字稿取课堂说法、从说课稿取设计理由，不虚构文件。

宣传中只写已核产品内容和交付能力；教师预设回答不写成真实学生反馈，建议课时不写成课堂实测，视频剪辑清单不写成成片。用户未要求时不发布、上传、修改原课件或处理成片。

# 课件小红书笔记制作

把已完成的课件及真实配套资料转成老师能看懂的一组笔记。独立于整课制作流程；不要求重做原课、运行十二模块或调用任何 `k12-courseware-*` Skill。

## 判断本次范围

- “想方案、选题、设计稿”：只交可审阅规划，不把规划说成成品。
- “制作一篇/修改某张”：只处理指定篇或图片，沿用已核来源与风格。
- “制作一组”：通常规划 4—5 篇，各篇有不同问题；常用 3 篇图文＋2 篇视频剪辑资料包。实际数量、形式服从用户要求和可用素材。素材不足时说明缺口，选择有依据的主题，不为凑数复述同一篇。
- 首版视频产物为**剪辑资料包**：实际封面、标题正文、可执行剪辑清单、选用素材及必要口播稿。用户自行剪辑；没有真实 MP4 成片就不写“视频已完成”。

## 生产顺序

文件位置遵循[每课四目录规范](../math-courseware-studio/references/workspace-layout.md)：沿用户已给定课程根读取03_final当前有效产品；笔记策划、排版与核查过程放02_work/notes，实际按篇交付包放04_notes/vNNN/note-NN，README注明当前版本与待剪辑状态。旧课复用其真实交付位置，不自动搬动；独立笔记任务不要求重跑或补造整课状态。

1. 先读工作目录 `AGENTS.md`、`HANDOFF.md` 及课程交接；检查现存文件和未提交改动。按[选题与来源](references/note-planning.md)核定当前 PPT、视频、教学设计、逐字稿、说课稿、学习单、黑板贴及已有宣传图。只使用已存在且能核对的文件；历史截图和修改时间不能单独决定采用版本。发现教材版本、页码、数学或视频画面冲突时先处理证据，不把冲突带入宣传图。
2. 为每篇写一句老师关心的问题，列独有证据、形式、图序或剪辑路径、交付文件。对照整组检查主题是否重复。用户已给具体设计方案时沿用，必要调整写明来源原因，不机械套固定的五主题。
3. 依据[图文制作](references/visual-production.md)完成可用封面与内容图；依据[视频剪辑资料](references/video-production.md)完成每篇视频包。真实课件页、尺图、数字和文稿局部用实际来源等比排版，不用生图重画事实内容。艺术封面按用户指定图像路线制作并目视核对；已有合适成品直接复用。
4. 按[文案与交付检查](references/copy-and-review.md)给每篇一条主标题和完整正文，核事实、数学、来源、手机缩图及文件可用性。可运行 `scripts/check_delivery.py` 做机械检查；它不能替代逐图目视、逐句读稿和视频实际看听。

## 交付边界

图文篇交实际封面、按序内容 PNG、标题正文；视频篇交实际封面、标题正文、剪辑清单、选用素材路径和必要口播文稿。内部来源/提示词/测试留在工作区，成品按篇放清楚。若已有符合主题的图，复用并记录来源，不无故再生。没有独立“讲课稿”时，从逐字稿取课堂说法、从说课稿取设计理由，不虚构文件。

宣传中只写已核产品内容和交付能力；教师预设回答不写成真实学生反馈，建议课时不写成课堂实测，视频剪辑清单不写成成片。用户未要求时不发布、上传、修改原课件或处理成片。

# 课件商品图与小红书笔记制作

把已完成的课件及真实配套资料转成商品图和笔记。默认顺序是**课件与配套完成并核对 → 商品主图与详情图 → 笔记素材**。可从Studio成品交付后进入，也可独立接入现有成品；不要求重做原课、运行十二模块或调用任何 `k12-courseware-*` Skill。

商品图按[专门流程](references/product-images.md)：三张主图沿已确认参考版式生图或局部编辑、详情取真实文件导出后程序拼版，默认无水印；第三主图学习单/电子版黑板贴不写数量，不写板书布局数量，使用真实具备的“可编辑PPT”格式名称。三张主图的“资源包含”、详情资源总览及商品内容介绍默认加入“希沃课件”，清单中紧跟PPT课件，由鹿鸣最后上传到希沃；提供承诺与实际上传状态按专门流程分别记录。商品图的完整规格与提示词不套用下方笔记封面、图数目标或3:4规则。

第1—5篇的封面继续采用鹿鸣已确认的**故事海报**：大课名、满版3D故事画面、突出角色，各篇按主题改变构图，详见[封面制作要求](references/visual-production.md)。沿本课已采用人物与画风；第6篇专用[浅色大字封面与逐字稿图解](references/illustrated-script.md)。用户当次指定的其他风格优先，已确认的方向直接沿用，不增加逐篇审批。

## 判断本次范围

- “想方案、选题、设计稿”：只交可审阅规划，不把规划说成成品。
- “商品图、商品主图和详情页”：进入[商品图分支](references/product-images.md)，只交三主图与按真实资料展开的详情，不自动扩为笔记整组。主图提示词见[三张模板](references/product-image-prompts.md)。
- “制作一篇/修改某张”：只处理指定篇或图片，沿用已核来源与风格。
- “制作一组/这门课的笔记素材”：默认每门课交**6篇，原5篇不变，第6篇追加逐字稿＋课件截图图文**，共4篇图文＋2篇视频封面文案。第1篇用本地排版1，第2篇由AI按内容从排版2/3/4中选一种，第3篇沿用原来的讲解/对照/配套图文样式，第4/5篇仍为视频封面文案；详见[整组分配与选版](references/note-planning.md)。第6篇按[逐字稿图解规范](references/illustrated-script.md)，沿课堂顺序忠实排版真实逐字稿与对应PPT截图。用户另有数量、形式要求时按当次要求；素材不足时说明具体缺口，不静默减篇或把不完整包称为完成。
- 两篇视频笔记默认只交**实际封面、标题、完整正文和话题**，视频内容由用户自行制作。不要额外制作或索取镜头图、剪辑清单、素材包、口播稿、字幕、时间线或固定时长；缺少用户自制视频不阻塞这四项交付。只有用户明确要求剪辑资料时才扩展为`video-edit-kit`，旧包保留。此调整不改变三篇图文规则。

## 生产顺序

文件位置按本课已有规则和[笔记目录约定](references/note-planning.md#整组目录)确定：五目录课从最终产品取源，商品图工作放中间文件/notes/product-images/vNNN、交付放商品详情/vNNN，笔记工作放中间文件/notes、交付放笔记素材/vNNN/note-NN。四目录及其他旧课沿真实位置续作，不自动搬动。README注明当前版本及“视频内容由用户自行制作”。本Skill接入已完成产品，不要求调用初始化器、升级整课运行时或补造整课状态。

1. 先读工作目录 `AGENTS.md`、`HANDOFF.md` 及课程交接；检查现存文件和未提交改动。按[选题与来源](references/note-planning.md)核定当前 PPT、视频、教学设计、逐字稿、说课稿、学习单、黑板贴及已有宣传图。文件画面与格式只取已存在且能核对的文件；用户明确最终提供的希沃课件另记声明及上传状态，不因暂缺本地文件从商品清单删除。历史截图和修改时间不能单独决定采用版本。发现教材版本、页码、数学或视频画面冲突时先处理证据，不把冲突带入宣传图。

2. 进入新一组笔记前，先按[商品图流程](references/product-images.md)完成三主图及详情并交付；同源且符合当前规则的整套可复用。只有商品图的请求到此结束。用户明确只做笔记、单篇或局部修订时沿指定范围，不强制补做商品图；商品图制作不替代教学成品完成条件，也不新增逐张采用等待。以下第3—5步仅用于笔记。

3. 为每篇写一句老师关心的问题，列主要证据、形式、图文图序或视频笔记的封面与文案重点、交付文件。前三篇整体选题、组织和正文各有侧重，同一张成品内容图可以跨篇复用，不设重复比例或强制改图。前三篇图文每篇以约10张含封面为目标，第6篇按逐字稿长度与手机可读性分页；按[图数与配套规划](references/note-planning.md)处理素材不足，用户指定数量优先。用户已给具体设计方案时沿用，必要调整写明来源原因。
4. 依据[图文制作](references/visual-production.md)完成可用封面与内容图；整组图文前两篇的课件主体按既定分配调用[本地排版工具](references/local-layout-tool.md)，显式传入模板、本课选页顺序、参数和全新工作目录，保存真实渲染来源，第2篇记录选版理由。第3篇使用原`dual/focus/companion`说明卡。各篇可安排多张“课件与配套资料组合图”：把真实课件页与同一教学环节的教学设计、逐字稿、说课稿、学习单、电子黑板贴或板书图对应展示，不限定每篇组合图张数或固定资料类型。按[交付格式](references/copy-and-review.md)标记实际来源，保留前两篇课件主体版式。单篇按其实际选题与用户指定版式。依据[视频笔记交付](references/video-production.md)完成两篇封面、标题、正文和话题。内容图从真实文件导出、截取或按原文排版，不用生图重画文字、刻度或答案；新艺术封面按用户指定图像路线制作并目视核对，已有合适成品直接复用。
5. 追加第6篇[逐字稿图解](references/illustrated-script.md)：浅色大字封面，按课堂顺序将教师原话、学生预设、操作提示与真实对应截图排成连续PNG；可附同课总览和实际配套。不把教学设计扩写成已有逐字稿，不编“听过课”“被夸”等经历；缺少匹配逐字稿时明确第6篇待补，不以五篇冒充整组完成。
6. 按[文案与交付检查](references/copy-and-review.md)给每篇一条主标题、完整正文和相关话题，核事实、数学、来源、手机缩图及文件可用性。运行 `scripts/check_delivery.py` 做机械检查；它不能替代逐图目视、逐句读稿。默认视频笔记仅核封面与文案，不额外安排视频看听或成片制作。

## 交付边界

商品图交三张方形主图、按序详情图、离线总览、来源清单及可直接使用的商品内容介绍`product-description.md`，按[商品图检查](references/product-images.md#目录来源与交付检查)执行；现有笔记检查器不支持该清单，不能用笔记的检查结果冒称商品图已核。下段格式、比例和篇数只用于笔记。

图文篇交实际封面、按序内容图、标题正文及话题：四种本地排版均为带渲染清单的原版式JPG，原解释卡与第6篇逐字稿正文图为PNG；视频篇默认每篇只交`00-cover.png`与`copy.md`（含标题、正文、话题），标记`format: "video-cover-copy"`。新默认整组在delivery.json标记`series_profile: "three-image-two-video-plus-script"`，顺序固定为原3图文、原2视频封面文案、第6篇逐字稿图解，使用`--expected-count 6`检查；第6篇正文图标`script-illustrated`并分别定位真实课件和逐字稿来源。旧五篇profile `three-image-two-video`和历史或明确另需的`video-edit-kit`保持兼容，不自动重做旧包。内部来源/提示词/测试留在工作区，成品按篇放清楚。完成当轮主动在聊天展示实际图、编号文件名、图序及整包目录；视频篇交代封面文案已交、内容由用户制作，不列待AI剪辑事项。若已有符合主题的图，复用并记录来源，不无故再生。没有独立“讲课稿”时，从逐字稿取课堂说法、从说课稿取设计理由，不虚构文件。

宣传中的产品内容和交付能力须有依据；希沃课件可以依据用户明确的提供承诺列入资源介绍，但未收到完成确认不能写成已上传，不虚构格式、链接或功能。教师预设回答不写成真实学生反馈，建议课时不写成课堂实测，视频剪辑清单不写成成片。用户未要求时不发布、上传、修改原课件或处理成片。

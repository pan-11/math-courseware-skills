# 文案与交付检查

每篇用一个主标题和一篇独立可读正文，先讲老师遇到的具体问题，再讲课件怎样处理，最后给资料用途或查看价值。默认标题尽量在20字以内，正文约250—400字；这是鹿鸣现有工作偏好，可按当次要求调整，不当作平台硬限制。不要编教材版次、课堂效果、销量、文件内容或未交付功能。

复核三个层面：

1. **事实与教学**：每个数字、页码、单位、视频对白、来源文件能追溯；错法要指出错因，非0起点不能一概写错；教师预设回答不冒充真实反馈。
2. **图文**：标题、封面、内容图、正文回答同一问题；人物与系列视觉一致；真图不失真，手机缩图能读到核心问题和关键结论。
3. **交付**：每篇文件真实存在、可打开且顺序清楚；图文有实际 PNG，视频有实际封面及可执行剪辑表。建议发布顺序只作编辑建议，不声称流量效果。

可在成品目录写`delivery.json`并运行`python scripts/check_delivery.py <delivery.json> --expected-count 5`；该脚本同样使用 Python 3.11+ 和 Pillow。单篇不传`--expected-count`。路径相对`delivery.json`所在目录，也可用绝对路径。格式：

```json
{
  "notes": [
    {
      "id": "01", "topic": "量法辨错", "format": "image",
      "cover": "01_量法辨错_图文/00_封面.png",
      "copy": "01_量法辨错_图文/标题与正文.md",
      "cards": ["01_量法辨错_图文/01_内容.png"]
    },
    {
      "id": "02", "topic": "故事导入", "format": "video-edit-kit",
      "cover": "02_故事导入_视频/封面.png",
      "copy": "02_故事导入_视频/标题与正文.md",
      "edit_list": "02_故事导入_视频/剪辑清单.md",
      "asset_list": "02_故事导入_视频/选用素材清单.md",
      "clips": [
        {"source": "C:/course/video1.mp4", "in_seconds": 12.4, "out_seconds": 17.8},
        {"source": "C:/course/final.pptx", "slide": 4}
      ]
    }
  ]
}
```

检查器核路径、文件非空、图像3:4与最低720像素宽、编号/主题唯一、视频片段正时长或有效页码；有新增解说时在视频篇加`narration`路径。可为每条`clips`添加`sha256`核源字节；不提供时仍要在人工来源表中确认版本。检查器不会判断图片文字、美观、数学和听辨，也不会验证发布平台规则。失败项先修正，再交最终目录。

# 文案与交付检查

以下清单及`scripts/check_delivery.py`适用于笔记。商品主图与详情图使用独立`manifest.json`，按[商品图检查](product-images.md#目录来源与交付检查)核三主图版式、第三张数量/名称规则及真实来源；不套笔记的3:4、每篇图数目标或五篇结构。

每篇用一个主标题和一篇独立可读正文，先讲老师遇到的具体问题，再讲课件怎样处理，最后给资料用途或查看价值。默认标题尽量在20字以内，正文约250—400字；这是鹿鸣现有工作偏好，可按当次要求调整，不当作平台硬限制。不要编教材版次、课堂效果、销量、文件内容或未交付功能。

复核三个层面：

1. **事实与教学**：每个数字、页码、单位、视频对白、来源文件能追溯；错法要指出错因，非0起点不能一概写错；教师预设回答不冒充真实反馈。课件与配套资料组合图逐句核原文和同一教学环节的对应关系，不能用同课其他段落冒充所示页面的讲解。多页配多段时逐项标对应页；逐字稿保留原话，教学设计/说课稿压缩标摘要，学习单保留条件和留白。板贴/板书取实际成品，组合画面标“使用示意”，核来源性质及手机可读性。
2. **图文**：标题、封面、内容图、正文回答同一问题；人物与系列视觉一致，真图不失真。默认封面对照[故事海报要求](visual-production.md)逐张查看原图和手机缩图：课名/主题可读、人物与动作突出、场景满版，各篇构图随主题变化，未退回小截图说明卡。内容图另核核心问题和关键结论可读；不要用文件齐备或检查器PASS代替封面效果核对。正文应分清宣传插画与真实产品画面，不将整组图片统称为课件截图。
3. **交付**：每篇文件真实存在、可打开且顺序清楚；图文有实际封面及内容图，原卡和组合图为PNG，本地四种排版按[本地工具规范](local-layout-tool.md)保留原版式JPG及对应渲染依据；视频默认有实际封面、标题、完整正文和相关话题。整组核第1篇课件主体排版1、第2篇主体所选2/3/4之一、第3篇原图文卡，以及两篇视频封面文案。图文按每篇约10张含封面的目标核实际数量与素材依据，不足时核原因；多张组合图逐张核对应和来源，同一成品图跨篇复用不判错，不设重复比例。封面按原规则。视频内容由用户制作，不把缺少剪辑表、镜头图、口播或用户成片当作默认交付缺项。建议发布顺序只作编辑建议，不声称流量效果。

在成品目录写`delivery.json`。默认整组在顶层加入`"series_profile": "three-image-two-video"`，`notes`按3篇`image`、2篇`video-cover-copy`排列，并运行`python scripts/check_delivery.py <delivery.json> --expected-count 5`；它会核每篇实际渲染模板，而非只看风格标签。历史或用户明确另需的`video-edit-kit`仍可作为视频篇校验，不能据此默认要求剪辑包。单篇或用户指定的其他组合不加此整组字段，数量按实际传入。脚本使用Python 3.11+和Pillow，路径相对清单所在目录，也可为绝对路径。视频篇`copy.md`首行为`# 标题`，中间为完整正文，末行为以空格分隔的`#话题`；两篇均需独立可用。下面仅演示原图文卡和默认视频篇字段，不是完整五篇清单；工具图片对象格式见[本地工具交付清单](local-layout-tool.md)：

```json
{
  "notes": [
    {
      "id": "01", "topic": "量法辨错", "format": "image",
      "cover": "01_量法辨错_图文/00_封面.png",
      "copy": "01_量法辨错_图文/标题与正文.md",
      "cards": ["01_量法辨错_图文/01_内容.png"]
    },
    {
      "id": "02", "topic": "故事导入", "format": "video-cover-copy",
      "cover": "note-02/00-cover.png",
      "copy": "note-02/copy.md",
      "video_producer": "user",
      "status": "封面与文案已交；视频内容由用户自行制作"
    }
  ]
}
```

课件与配套资料组合图放在`cards`的实际阅读位置，继续以`kind: "teaching-companion"`标记，包括第3篇融入原`companion`版式的图片；同篇可以有多个对象。`material_type`支持`teaching-design`（教学设计）、`verbatim-script`（逐字稿）、`lesson-presentation`（说课稿）、`worksheet`（学习单）、`blackboard-stickers`（电子黑板贴）、`blackboard-layout`（板书图）。一图含多种资料时按主要讲解对象填类型，并完整列出所有来源。

`sources`列实际课件与配套原件，`ref`写清文稿段落/页码、学习单任务或板贴图号及对应课件页；PPT页码和文稿自身页码分别标，不要求两者数字相等。多张板贴分别列来源；局部图与原件关系继续保存在工作区来源表。单独的整课说明标明范围，不伪造单页对应。复用成品图保留相同来源依据，可复制到各篇目录，不要求为了复用重绘或改写。下列对象可按图序加入，不替代前两篇全部工具图：

```json
{
  "file": "note-01/04-teaching-design.png",
  "kind": "teaching-companion",
  "material_type": "teaching-design",
  "sources": [
    {"file": "C:/course/最终产品/courseware.pptx", "ref": "P08 探究任务页"},
    {"file": "C:/course/最终产品/teaching-design.docx", "ref": "探究环节第2段；对应课件P08的任务组织"}
  ]
}
```

检查器核路径、文件非空、编号/主题唯一；`video-cover-copy`另核标题、正文和末行话题，不要求视频、镜头图、剪辑清单或时长，也不接受混入这些制作字段。封面、普通字符串内容卡及显式组合图要求真实PNG编码、3:4和最低720像素宽；组合图逐张核上述材料类别、非空来源文件与定位记录。显式`courseware-layout`内容卡另按四种已支持模板的成功清单核JPEG编码、最低宽度、实际尺寸及输出SHA256。组合图不设每篇上限，不因跨篇图片相同而拒绝；含封面约10张是规划目标，不作为机械数量门槛。扣除组合图后，第1篇仍须有排版1课件图、第2篇仍须有2/3/4中的同一种课件图，第3篇保持原PNG卡（可含组合图）。没有组合图或只有一张的旧清单仍兼容；新制作有真实相关资料时按需加入，省略原因由人工复核。用户明确指定其他组合时按实际范围，不套默认整组字段。

仅校验历史或明确要求的完整`video-edit-kit`时，保留`edit_list`、`asset_list`、`clips`及可选`narration`规则；实际视频片段需正入出点、PPT需页码、静态图需保留时长，可附`sha256`核源字节，具体制作见[可选剪辑资料](video-production.md)。默认封面文案交付不生成这些字段，也不承诺尚未制作的镜头/时长。检查器不会判断摘录与原文是否一致、所标课件页与文稿是否确为同一环节、资料是否为当前采用版、图片文字、美观、数学和听辨，也不会验证发布平台规则；这些需实际内容复核。失败项先修正，再交最终目录。

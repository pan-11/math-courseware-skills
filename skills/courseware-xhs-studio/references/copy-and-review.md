# 文案与交付检查

每篇用一个主标题和一篇独立可读正文，先讲老师遇到的具体问题，再讲课件怎样处理，最后给资料用途或查看价值。默认标题尽量在20字以内，正文约250—400字；这是鹿鸣现有工作偏好，可按当次要求调整，不当作平台硬限制。不要编教材版次、课堂效果、销量、文件内容或未交付功能。

复核三个层面：

1. **事实与教学**：每个数字、页码、单位、视频对白、来源文件能追溯；错法要指出错因，非0起点不能一概写错；教师预设回答不冒充真实反馈。配套卡逐句核实际文稿，逐字稿摘录保留原话，教学设计压缩标“环节摘要”；板贴取实际成品，组合画面标“使用示意”，核与对应课件页的关系及手机可读性。
2. **图文**：标题、封面、内容图、正文回答同一问题；人物与系列视觉一致，真图不失真。默认封面对照[故事海报要求](visual-production.md)逐张查看原图和手机缩图：课名/主题可读、人物与动作突出、场景满版，各篇构图随主题变化，未退回小截图说明卡。内容图另核核心问题和关键结论可读；不要用文件齐备或检查器PASS代替封面效果核对。正文应分清宣传插画与真实产品画面，不将整组图片统称为课件截图。
3. **交付**：每篇文件真实存在、可打开且顺序清楚；图文有实际封面及内容图，原卡和配套卡为PNG，本地四种排版按[本地工具规范](local-layout-tool.md)保留原版式JPG及对应渲染依据；视频有实际封面及可执行剪辑表。整组核第1篇课件主体排版1、第2篇主体所选2/3/4之一、第3篇原图文卡，以及两篇视频资料包；每篇最多1张显式配套卡，紧跟相关课件图，第3篇融入原组合卡，无资料时核已记录的省略原因。封面按原规则。建议发布顺序只作编辑建议，不声称流量效果。

在成品目录写`delivery.json`。默认整组在顶层加入`"series_profile": "three-image-two-video"`，`notes`按3图文、2视频排列，并运行`python scripts/check_delivery.py <delivery.json> --expected-count 5`；它会核每篇实际渲染模板，而非只看风格标签。单篇或用户指定的其他组合不加此整组字段，数量按实际传入。脚本使用Python 3.11+和Pillow，路径相对清单所在目录，也可为绝对路径。下面仅演示原图文卡和视频篇字段，不是完整五篇清单；工具图片对象格式见[本地工具交付清单](local-layout-tool.md)：

```json
{
  "notes": [
    {
      "id": "01", "topic": "量法辨错", "format": "image",
      "cover": "01_量法辨错_图文/00_封面.png",
      "copy": "01_量法辨错_图文/标题与正文.md",
      "cards": ["01_量法辨错_图文/01_内容.png"]
    },
    {
      "id": "02", "topic": "故事导入", "format": "video-edit-kit",
      "cover": "02_故事导入_视频/封面.png",
      "copy": "02_故事导入_视频/标题与正文.md",
      "edit_list": "02_故事导入_视频/剪辑清单.md",
      "asset_list": "02_故事导入_视频/选用素材清单.md",
      "clips": [
        {"source": "C:/course/video1.mp4", "in_seconds": 12.4, "out_seconds": 17.8},
        {"source": "C:/course/final.pptx", "slide": 4}
      ]
    }
  ]
}
```

新增配套卡也放在`cards`的实际阅读位置，以`kind: "teaching-companion"`明确标记；包括第3篇融入原`companion`版式的那张。`material_type`为`teaching-design`（教学设计）、`verbatim-script`（逐字稿）或`blackboard-stickers`（电子黑板贴）；`sources`列出实际原文稿/板贴文件，`ref`写清段落、页码或图号及对应课件页。多张板贴分别列来源；渲染用的局部图与原件关系继续保存在工作区来源表。可按选题调换材料类型，检查器不强绑某篇某类。下列对象插在相关课件图之后，不能替代前两篇全部工具图：

```json
{
  "file": "note-01/04-teaching-design.png",
  "kind": "teaching-companion",
  "material_type": "teaching-design",
  "sources": [
    {"file": "C:/course/03_final/teaching-design.docx", "ref": "探究环节第2段；配合课件P08"}
  ]
}
```

检查器核路径、文件非空、编号/主题唯一、视频片段正时长或有效页码。封面、普通字符串内容卡及显式配套卡要求真实PNG编码、3:4和最低720像素宽；配套卡还核材料类别、非空来源文件与定位记录。显式`courseware-layout`内容卡另按四种已支持模板的成功清单核JPEG编码、最低宽度、实际尺寸及输出SHA256。默认整组每篇最多1张配套卡；扣除配套卡后，第1篇仍必须有排版1课件图、第2篇仍必须有2/3/4中的同一种课件图，不能以普通PNG或配套卡替代，第3篇保持原PNG卡（可含配套组合卡）。没有配套卡的旧清单仍兼容；新制作有真实相关资料时按默认加入，省略原因由人工复核，不把配套卡缺失自动判成整课失败。用户明确指定其他组合时按实际范围，不套默认整组字段。有新增解说时在视频篇加`narration`路径。可为每条`clips`添加`sha256`核源字节；不提供时仍要在人工来源表中确认版本。检查器不会判断摘录与原文是否一致、资料是否为当前采用版、图片文字、美观、数学和听辨，也不会验证发布平台规则。失败项先修正，再交最终目录。

# 商品主图与详情图

鹿鸣已确认的方式：**三张主图按参考商品版式实际生图或局部编辑；详情用当前课件、文稿和配套原文件导出，再程序拼版。默认不加店铺水印。** 商品图是课件与配套完成后的独立产物，先于新一组笔记素材；三张商品主图与笔记封面分别制作，不互相替代。

## 开始与复用

1. 核定本课已完成且当前有效的PPT、配套文件、版本与已有验收记录。整课沿Studio的成品核对与汇合要求；独立接入只核真实成品，不要求重跑整课或补造历史状态。仅文件名带“最终”或控制器退出0不能证明源文件已完成。
2. 保存来源清单：课题/年级，文件路径与SHA256，PPT总页数、视频页及已核段数，各文稿类型/格式/页数，电子版黑板贴文件及实际编辑能力；希沃课件另记用户提供承诺与真实上传状态，见下节。沿已有视频检查约定与同版记录，不为制作商品图重看、探测或抽帧已确认视频；未知媒体数量不写进卖点。其他资料缺失时先定位已有成品或说明缺项，不用生图伪造资料。
3. 同源版本、当前文案规则和版式均满足的商品图直接复用；只有受影响部分换版。只改资源名称、清单或说明时，先实看当前主图，将其作为图像工具的编辑目标，冻结完整最终正文并明确保留角色、场景、标题和版式；不要为改字重构整张画面。未变详情按原字节复用，只更新受影响的资源总览与商品介绍。旧样图中的数量不能自动套到另一课；课件或文稿换版则核相应详情、数量及文件名。
4. 全流程顺序为“课件与配套完成并核对 → 商品图制作/自检/交付 → 笔记选题与素材”。新一组笔记先检查商品图；用户明确只做笔记、单篇或局部修订时服从当次范围。只要商品图则交完商品图即结束。用户只要方案时只交方案，不新增生图。

## 希沃课件与资源描述

鹿鸣已明确商品还包含一份“希沃课件”，由鹿鸣在最后上传到希沃。后续默认将其与PPT课件并列列入商品资源；不因当前没有本地希沃文件删去这一项，不要求每课重新确认同一提供安排。用户当次明确调整资源范围时按当次要求。

- **出现位置**：主图一左下“资源包含”、主图二文件清单、主图三“资源包含”正文、详情页资源总览，以及商品说明或笔记中介绍“包含哪些资料”的段落都加入“希沃课件”。常用表述为“包含PPT课件、希沃课件及〔本课实际配套资料〕”；不要求每张实页预览重复该项。
- **来源与状态**：来源清单单独记录“提供依据：用户已明确最终提供；负责上传：鹿鸣；上传状态：待用户上传确认”。这表示商品包含该资源，不表示已经上传完成。没有实际本地文件时不编文件路径、SHA256或`.enbx`格式，不编希沃分享链接、专属互动或可编辑能力；其他文件仍按真实成品核对。
- **更新与交接**：收到用户明确上传完成确认或可核验交付依据后，再更新对应状态及实际链接/文件信息。商品图可以先完成，交接中保留由鹿鸣最终上传的事项；不能把“商品图已交”写成“希沃已上传”或“全部商品资源已交齐”。本规则不授权代用户上传。

## 第三张主图的文字规则

- **学习单不写数量**：写“课堂学习单”，不写页数、张数、份数或题数。
- **黑板贴不写数量**：统一称“电子版黑板贴”，不写张数、件数、套数；不出现“两套板书布局”或其他布局数量，默认不单列板书布局项。
- **格式名称**：写“可编辑PPT”，不用“可移动PPT”。这只替换宣传用语，不改实际文件名；须核所指文件确有可编辑对象，不将一页一图的PPT宣传为内容可编辑。没有该格式时按真实文件写，不为套模板补造能力。
- 商品主图涉及该配套时统一用“电子版黑板贴”。主图一、二及详情资源总览也沿已确认样张，默认只列学习单/电子版黑板贴名称及真实格式，不附数量或板书布局卖点；来源清单中的真实数量、教学内容和逐页详情的页码照常保留。
- 课件页数、已核视频段数、教学设计/逐字稿/说课稿页数可以据实写；没有数据则省略数量。严禁照抄某个示例课的数字。
- 未提供店铺条款时只写电子资料性质、实际内容/格式和购买前核对提示；不虚构发货方式、退款政策、价格、版权/售后承诺或“赠品”。

第三张的常用句式为：“资源包含：〔已核PPT课件信息〕、希沃课件及〔实际教师文稿〕，配套课堂学习单和电子版黑板贴。”“文件形式：〔实际课件/文稿格式〕；电子版黑板贴提供透明PNG和可编辑PPT。”希沃课件按上节提供安排保留，其余资料与格式以真实成品为准。出图前冻结正文，出图后核实际图片没有漏掉希沃课件，也没有自行补上学习单/板贴数量或旧用语。

## 详情：真实文件导出与程序排版

详情的教学画面不调用生图重画。原课件中的AI插画是既有来源，不是本次详情生成的新图片；向用户说明实际制作方式。

- **课件**：优先复用同一当前PPT的已核页图，否则用实际可用的WPS/Office渲染导出静态页。视频页按已有约定处理，通常展示其他静态页，并区分PPT总页数与实际预览页数；不拿封面截图或虚构画面代替视频检查。
- **希沃课件**：在资源总览与资料介绍中列出。上传前可沿用真实PPT页作为“课件内容预览”，不冒充希沃实机截图，不用生图伪造软件界面或功能；有实际希沃文件/页面后，按核实来源补展示。
- **文稿**：教学设计、课堂逐字稿、公开课说课稿、课堂学习单按真实文件类型展示。用同版PDF渲染；只有DOCX时用可用Office工具转PDF再渲染。已有同版页图可复用，核页序、分页与文字清晰度。
- **电子版黑板贴**：使用实际透明贴片与已有整板预览；保留文字、公式和条件，按实际数量展开。没有整板图时可把真实贴片排成明确的使用示意，不能冒充新增教学附件。
- **拼版**：用Pillow或HTML/CSS等确定性排版，等比放置真实图像并加栏目标题/原页码。课件可用两列实页拼图，重点页单独放大；文稿通常每图纵向放1—2张完整页。保留题目条件、单位、公式与作答区，不拉伸、不覆盖关键内容；文字密时减少同图页数。
- **顺序与数量**：首张详情为独立资源总览，随后按代表性课程实页、课件页序预览、贴片/整板、各类文稿展开。资源总览由来源清单排版，PPT与希沃分行，随后列实际教师文稿、学习单和电子版黑板贴；视频可合入PPT说明，格式与主图保持一致。栏目和图数随本课资料确定，不固定为25张；默认按实际内容完整展开，用户指定摘选时明确展示范围。详情默认1440像素宽JPG，高度随内容，原清晰度不足先提高实际文件渲染质量。

商品详情的整套资料展示不套每篇笔记图数目标、三篇本地排版分配或笔记封面3:4比例；笔记的这些制作约定不限制商品详情展示真实资料。

- 工作区保存真实来源表/哈希、希沃课件的用户声明与上传状态、主图冻结正文和完整提示词/工具返回、静态导出及程序拼版记录、图片检查和HANDOFF。

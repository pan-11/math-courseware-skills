# 选题与来源

## 先定输入

优先读取用户指明或已经确认的最终交付版 PPT；对照交接、实际文件哈希、页数与媒体。只看到一个文件名时不能推断它已完成。列出实际存在的四类教学资料、学习单页数、黑板贴成品、已有封面/内容图；没有的项目标为缺失，不写进卖点。保留原件与旧交付，新的宣传图使用独立版本目录。

建立简短的来源表：`主张｜课件页/文稿段/视频时段｜源文件｜已核状态｜限制`。视频画面先看，涉及对白再听；只有抽帧时不写“对白已核”。截图若来自旧版，必须与本次采用的课件对照。教材版本、学段、课时、数量和配套名称只按实际证据写。

## 选题

每篇只回答一个老师愿意点开的具体问题。先挑有可见证据的内容，再选图文或视频；允许共享课题、角色和少量关键页，不让数篇重复同一展开。常见角度是整课怎样上、故事/操作怎样引出问题、一个错法怎样纠正、一个难点怎样讲清、配套怎样一起用。它们是候选，不是固定模板。

默认有依据时做 3 图文＋2 视频；只有一段适合剪辑的动态素材时可做 3 图文＋1 视频。用户指定形式优先；若指定的视频缺真实可用源，说明缺口并给可执行替代方案，不能编造镜头。视频篇数是新笔记篇数，不等于原 PPT 内视频段数。

每篇规划包含：编号、读者问题、形式、主证据、次证据、图序或镜头顺序、一句和其他篇的差异、应交文件。只要方案时到此为止；明确要求制作时继续交成品，不增加逐篇审批。

## 整组目录

新课按[四目录规范](../../math-courseware-studio/references/workspace-layout.md)使用同一课程根：已核产品取自03_final，策划/排版/草稿与证据留02_work/notes及_state，交给用户的笔记组放04_notes/vNNN并更新该区README。每篇note-NN含自己的图、文、所选片段及用法；manifest/清单记录源课件版本与页码/时间码。下面篇名是阅读标签示例，默认磁盘名沿项目英文规则；已有明确的中文交付约定可沿用。

成品可按`01_主题_图文/`、`02_主题_视频/`分篇；图文放`00_封面.png`、顺序内容 PNG、`标题与正文.md`，视频放`封面.png`、`剪辑清单.md`、`选用素材清单.md`、`标题与正文.md`和需要时的`口播文稿.txt`。总览写各篇独立主题、素材状态和建议发布顺序。目录是建议，沿用用户现有交付约定时不强制搬动旧文件。

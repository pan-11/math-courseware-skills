# 选题与来源

新一组笔记素材开始前，先核[商品主图与详情图](product-images.md)是否已按当前成品和规则完成；没有则先制作并交付，同版有效则复用。只有方案、单篇/局部修订或明确只做笔记时保留当次范围。本文件的六篇分配和图数目标只用于笔记，不限制商品详情中的整套文稿展示。

## 先定输入

优先读取用户指明或已经确认的最终交付版 PPT；对照交接、实际文件哈希、页数与媒体。只看到一个文件名时不能推断它已完成。列出实际存在的四类教学资料、学习单页数、黑板贴成品、已有封面/内容图；没有的项目标为缺失，不写进卖点。保留原件与旧交付，新的宣传图使用独立版本目录。

建立简短的来源表：`主张｜课件页/文稿段/视频时段｜源文件｜已核状态｜限制`。确需引用视频画面或对白时沿本课已有检查约定核依据；只有抽帧时不写“对白已核”。默认视频封面文案可取已核课件和文稿，不要求提供或重审用户自制视频。截图若来自旧版，必须与本次采用的课件对照。教材版本、学段、课时、数量和配套名称只按实际证据写。

## 选题

每篇只回答一个老师愿意点开的具体问题。先挑有可见证据的内容，再选图文或视频；可以共享课题、角色、课件页和同一张成品内容图，三篇整体的选题、图序组织和正文各有侧重。常见角度是整课怎样上、故事/操作怎样引出问题、一个错法怎样纠正、一个难点怎样讲清、配套怎样一起用。它们是候选，不是固定模板。

默认每门课做**6篇：原3篇图文＋原2篇视频封面文案＋第6篇逐字稿图解**，保留原五篇编号、分工和封面规则，按下表追加。用户指定数量、形式优先；视频内容由用户自行制作，AI只完成两篇封面、标题、正文和话题。选题事实依据不足时说明缺口，不编造内容；缺少用户自制视频本身不阻塞这四项制作。视频篇数是新笔记篇数，不等于原PPT内视频段数。

| 篇次 | 内容图片/素材方式 | 制作决定 |
| --- | --- | --- |
| 图文1 | 本地排版1 `watermark` | 实际课件页的缩略总览＋大图展示；可穿插同环节教学设计、逐字稿等组合图，说明整课怎样组织 |
| 图文2 | 本地排版2/3/4中选一种 | AI按本篇问题、页内容密度和阅读路径选择，并记录理由；可加入同页追问、活动设计或说课理由，展开本篇难点；用户已指定则沿用 |
| 图文3 | 原`dual/focus/companion`图文卡 | 真实页面＋对照、重点解释或关系说明；可展示学习单对应任务、电子黑板贴或板书的使用关系，不强制换成工具拼图 |
| 视频1、视频2 | 封面＋标题、正文和话题 | 每篇独立选题，复用已核产品事实；视频内容由用户制作，不额外交镜头图、剪辑表、口播或时间线 |
| 第6篇图文 | 浅色大字封面＋逐字稿与对应课件截图 | 按课堂顺序连续展示教师原话、学生预设与操作提示；按[专门规范](illustrated-script.md)分页，可附少量真实总览与配套图 |

前三篇图文各有一套有序素材与独立文案；同一张已经核过来源的成品内容图可以在不同篇直接复用，不设重复比例，不要求为了区分而重画、换裁切或改标题。整体不能只换版式、照搬相同选题和正文。前五篇封面继续原有艺术封面制作规则；排版工具内称作“封面页/首图”的输出只是内容展示图，不替换笔记封面。第6篇以连续课堂讲述为主线，独立交图序和文案，封面采用浅色大字；不能只复制第3篇的几张配套卡就称为逐字稿图解。

## 图数与配套规划

前三篇图文以**10张左右（含封面）**为制作目标，真实相关资料充足时安排超过8张。此数为制作偏好，不是平台限制或检查器硬门槛；用户另定数量时沿用。素材不足时记录实际张数和原因，不用重复堆图、无关片段或虚构资料凑数。第6篇按原逐字稿长度和手机阅读分页，保留课堂主线与必要对话，不为凑十张截断或缩小文字；缺少匹配逐字稿时明确第6篇待补，不能静默交五篇作为完整整组。

保留课件展示主体，各篇按问题安排多张“课件与配套资料组合图”，不限定每篇组合图张数，也不固定一篇只能使用一种资料。可用教学设计说明怎样组织、逐字稿呈现怎样提问、说课稿解释设计理由、学习单展示任务承接、电子黑板贴或板书图展示如何归纳。每张只选与所展示课件页同一环节的必要片段；可同图对应，也可紧接相关课件图作文稿细读。缺少成品或不相关时说明并省略，不扩大为新文稿制作或增加审批。具体配对和摘录方法见[图文制作](visual-production.md)。

第2篇的选版标准：排版2 `product`适合带主题标题的精选组合，优先有真实完整的“前2页＋每组5页”素材；原模板尾组缺图会显示占位，无法选出足够合适页面时改选3或4，不造图凑数。排版3 `direct-133-33`适合先看7页紧凑总览、随后看其余页面，前7页不会再生成大图；前7页文字密集或关键题目必须细读时应选4。排版4 `direct-1222-3-3`适合总览后逐组细看全部选页，尤其题干、数字、步骤较多的内容。依据实际内容判断，不随机选、不默认把2/3/4全出一遍。详细分组与参数见[本地工具](local-layout-tool.md)。

每篇规划包含：编号、读者问题、形式、主证据、次证据、图文图序或视频笔记封面与文案重点、一句和其他篇的差异、应交文件；图文篇另记含封面的实际图数、图片制作方式、第2篇所选模板及理由，以及每张组合图的材料类型、实际源文件/段落或图号、对应课件页、插入位置和课堂用途。第6篇另列逐字稿段落与PPT页/显示状态逐项映射、连续图序和浅色封面方案。复用成品图记录原文件，调换、省略或图数不足时写明依据。只要方案时到此为止；明确要求制作时继续交成品，不增加逐篇审批。

## 整组目录

先读本课已有AGENTS、HANDOFF和用户指定的成品地址，按实际布局取源与交付；本Skill只接入完工产品，不调用整课初始化器或要求某个`--layout`枚举。整课工作区另见[课程目录规范](../../math-courseware-studio/references/workspace-layout.md)，不因该模块版本或目录名称不同而迁移已开工课程。

同一课程根下只创建本次需要且先声明用途的目录。没有旧目录约定的独立任务，默认采用五个中文目录中的相应用途位置，原成品仍从用户给定地址读取，不移动原件。每篇note-NN含该形式应交的图与文；manifest/清单记录源版本与事实定位，并更新笔记区README。下面篇名是阅读标签示例，默认磁盘名沿项目英文规则；已有明确中文交付约定可沿用。

成品可按`01_主题_图文/`、`04_主题_视频/`分篇；默认第1—3篇图文、第4/5篇视频封面文案、第6篇逐字稿图解，英文目录依次`note-01`至`note-06`。图文放`00_封面.png`、按序内容图（原卡PNG；[本地四种排版](local-layout-tool.md)课件图为原版式JPG）、`标题与正文.md`；第6篇沿英文名交`00-cover.png`、按序正文PNG和`copy.md`，视频默认只放`00-cover.png`和`copy.md`（标题、正文、话题）；另有项目必需的目录规则不算视频制作素材。总览写各篇独立主题、图片方式、实际交付和“视频内容由用户自行制作”，不将旧剪辑要求带入新版。旧五篇包保留，明确要求五篇时沿原分工；只有明确追加剪辑资料才按[可选视频资料流程](video-production.md)扩展。沿用用户现有交付约定，不强制搬动旧文件。

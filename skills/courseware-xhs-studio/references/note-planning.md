# 选题与来源

## 先定输入

优先读取用户指明或已经确认的最终交付版 PPT；对照交接、实际文件哈希、页数与媒体。只看到一个文件名时不能推断它已完成。列出实际存在的四类教学资料、学习单页数、黑板贴成品、已有封面/内容图；没有的项目标为缺失，不写进卖点。保留原件与旧交付，新的宣传图使用独立版本目录。

建立简短的来源表：`主张｜课件页/文稿段/视频时段｜源文件｜已核状态｜限制`。视频画面先看，涉及对白再听；只有抽帧时不写“对白已核”。截图若来自旧版，必须与本次采用的课件对照。教材版本、学段、课时、数量和配套名称只按实际证据写。

## 选题

每篇只回答一个老师愿意点开的具体问题。先挑有可见证据的内容，再选图文或视频；允许共享课题、角色和少量关键页，不让数篇重复同一展开。常见角度是整课怎样上、故事/操作怎样引出问题、一个错法怎样纠正、一个难点怎样讲清、配套怎样一起用。它们是候选，不是固定模板。

默认每门课做3篇图文＋2篇视频剪辑资料包，按下表分配。用户指定形式优先；视频源不足时说明具体缺口，保留未完成状态并给可执行方案，不能编造镜头或自动减为一篇后称整组完成。视频篇数是新笔记篇数，不等于原PPT内视频段数。

| 篇次 | 内容图片/素材方式 | 制作决定 |
| --- | --- | --- |
| 图文1 | 本地排版1 `watermark` | 实际课件页的缩略总览＋大图展示；默认加1张教学设计片段卡，展示一个环节的任务、提问和设计意图 |
| 图文2 | 本地排版2/3/4中选一种 | AI按本篇问题、页内容密度和阅读路径选择，并记录理由；默认加1张逐字稿片段卡，展示对应页面的2—4句引导或追问；用户已指定则沿用 |
| 图文3 | 原`dual/focus/companion`图文卡 | 真实页面＋对照、重点解释或关系说明；默认用1张`companion`组合卡展示实际电子黑板贴及课堂用法，不强制换成工具拼图 |
| 视频1、视频2 | 原视频剪辑资料流程 | 每篇独立选题、封面、文案和可执行剪辑资料，待用户剪辑 |

三篇图文各有一套素材与独立文案，允许复用必要课件页，但不能只换版式、照搬相同选题和正文。封面继续原有艺术封面制作规则；排版工具内称作“封面页/首图”的输出只是内容展示图，不替换笔记封面。

课件展示为主，每篇最多1张配套内容卡，紧跟对应课件图；第3篇融入既有组合卡，不再额外加一张重复展示。默认三篇各展示一种配套，AI可依据选题和实际成品调换，不机械凑齐三种资料。只摘一个环节或小片段，说明怎样配合上课；缺少成品或与主题不相关时，在规划/来源表记录原因并省略，不虚构附件、扩大为新文稿制作或增加审批。制作和摘录边界见[图文制作](visual-production.md)。

第2篇的选版标准：排版2 `product`适合带主题标题的精选组合，优先有真实完整的“前2页＋每组5页”素材；原模板尾组缺图会显示占位，无法选出足够合适页面时改选3或4，不造图凑数。排版3 `direct-133-33`适合先看7页紧凑总览、随后看其余页面，前7页不会再生成大图；前7页文字密集或关键题目必须细读时应选4。排版4 `direct-1222-3-3`适合总览后逐组细看全部选页，尤其题干、数字、步骤较多的内容。依据实际内容判断，不随机选、不默认把2/3/4全出一遍。详细分组与参数见[本地工具](local-layout-tool.md)。

每篇规划包含：编号、读者问题、形式、主证据、次证据、图序或镜头顺序、一句和其他篇的差异、应交文件；图文篇另记图片制作方式、第2篇所选模板及理由，以及配套卡的材料类型、实际源文件/段落或图号、对应课件页、插入位置和课堂用途。调换或省略时写一句依据。只要方案时到此为止；明确要求制作时继续交成品，不增加逐篇审批。

## 整组目录

新课按[四目录规范](../../math-courseware-studio/references/workspace-layout.md)使用同一课程根：已核产品取自03_final，策划/排版/草稿与证据留02_work/notes及_state，交给用户的笔记组放04_notes/vNNN并更新该区README。每篇note-NN含自己的图、文、所选片段及用法；manifest/清单记录源课件版本与页码/时间码。下面篇名是阅读标签示例，默认磁盘名沿项目英文规则；已有明确的中文交付约定可沿用。

成品可按`01_主题_图文/`、`04_主题_视频/`分篇；默认前三篇图文、后两篇视频。图文放`00_封面.png`、按序内容图（原卡PNG；[本地四种排版](local-layout-tool.md)课件图为原版式JPG）、`标题与正文.md`，视频放`封面.png`、`剪辑清单.md`、`选用素材清单.md`、`标题与正文.md`和需要时的`口播文稿.txt`。总览写各篇独立主题、图片方式、素材状态和建议发布顺序。目录是建议，沿用用户现有交付约定时不强制搬动旧文件。

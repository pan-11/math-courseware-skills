# 三张商品主图提示词

本文件对应[商品图流程](product-images.md)。先从真实成品及用户明确提供的希沃课件建立资源清单并冻结三张正文，再把下列字段全部替换为实际内容，按每张一调用交给图像工具；不得把未填字段发给模型。保存最终完整请求，而不是只存模板或“同上”。希沃课件由鹿鸣最后上传，三张图的资源区均保留这一项，不因暂缺本地文件删去，也不写成已上传；其他没有的资源删除对应短语/清单行，不补造课件视频、文稿或可编辑能力。

参考分工：商品参考只约束版式；当前课程封面/人物/场景约束内容、画风与角色。参考路径来自当前可读文件，不写死示例课或本机路径。用户提供参考图时先实看；没有旧图时使用下面已经确定的版式，不要求用户重新找链接。三图均不加水印、账号、店铺名、二维码和未提供的购买条款。

已有合适主图且本次只改资源文案时，先实看旧图，将它标为“编辑目标”；请求中明确保留当前人物、场景、标题和版式，按下方模板给出完整最终文字，不让模型沿用旧清单或旧数量。只有受影响主图进入编辑，未变实页详情按原字节复用。

## 主图一：课程场景＋黄条＋底部双栏

```text
用途：小红书电子课件商品主图。制作一张高清1:1方形成图。
版式参考：〔当前可用商品主图参考；如无，则按以下完整版式〕。
人物/画风/场景参考：〔本课实际封面与已定角色/教学对象〕。
课题：〔真实课题〕；副标题：〔本课已有故事名或真实主题〕；学段：〔已核年级与学科〕。

按参考商品的结构制作：上方约55%为醒目的大场景和大标题，角色/教学对象突出；场景下沿叠放两条亮黄色横条，用极粗黑字列资源。下方约45%分成左白底文件清单、右浅黄色说明，左约43%、右约57%。不要做深绿仪表盘或小截图说明卡。
课名用大字、粗白描边，手机缩图可读；场景沿当前课件的风格，不复制其他课程角色。宣传场景不冒充PPT实页，不重画具体题目、刻度或公式。
第一条黄底黑字，逐字写：〔已核课件信息，可含页数与实际视频段数〕。
第二条黄底黑字，逐字写：〔实际配套类型，用＋连接，黑板贴写“电子版黑板贴”〕。
左下白底，黄色“资源包含”胶囊标题，小文件/文件夹图标和以下清单，逐行写：
〔按PPT课件、希沃课件、视频备份、教学设计、课堂逐字稿、公开课说课稿、课堂学习单、电子版黑板贴排序的本课清单；希沃紧跟PPT且只写名称；其他项目按实际资料增减，不固定行数。学习单/板贴默认只列名称与真实格式，不写数量〕
右下浅黄底，大红字“购买前请看”，黑字正文、重点红色，逐字写：
〔已核电子资料性质、实际文稿格式和购买前查看详情的简短说明〕
全部文字准确清晰，留边不裁切；控制每行字数，不把清单挤成小字。
不加水印、店名、账号、网址、二维码、价格、赠品承诺、发货退款或其他未提供条款。
```

```text
用途：小红书电子课件商品资源清单。制作一张高清1:1方形成图。
版式参考：〔当前可用资源清单参考；如无，则按以下完整版式〕。
纯白背景，顶部居中放亮黄色大胶囊标题“资源包含”，白字粗黑描边，两端可用白色小圆点。下面是宽松的竖向文件列表：左侧彩色文档/文件夹图标，右侧黑色大字，行间极浅灰细分隔线。保持参考的文件清单感，不加卡片框、仪表盘或绿色背景。
按以下资源清单逐行渲染，顺序和文字准确，不截断、不用省略号：
〔按PPT课件、希沃课件、课件内视频备份、教学设计、课堂逐字稿、公开课说课稿、课堂学习单、电子版黑板贴排序的本课清单；希沃项按用户提供承诺保留，其他不存在的行不保留，不固定八行。PPT/视频/教师文稿可写已核数量，学习单/板贴默认不写数量〕
电子版黑板贴末行下方用金色补充：〔按实际格式写“透明PNG＋可编辑PPT”或其中已有的一项，不写“可移动PPT”，不附板书布局卖点；没有格式依据则省略补充〕。
图标只区分格式，不假造文件管理器或软件截图。确保每行及底部补充完整可读。
不加水印、账号、店名、二维码、价格、赠品字样或其他未提供信息。
```

## 主图三：购买须知

先单独核下面正文：“资源包含”保留希沃课件；学习单只有名称，没有页/张/份/题数；电子版黑板贴没有张/件/套数；没有“两套板书布局”或其他布局项，没有“可移动PPT”。PPT课件及前三类教师文稿的数量按已核信息填写或省略，不把PPT页数直接当成希沃页数。`四类文稿`描述类型，不是学习单数量。

```text
用途：小红书电子课件商品购买前资料说明。制作一张高清1:1方形成图。
版式参考：〔当前可用购买须知参考；如无，则按以下完整版式〕。
顶部白底，巨大的红色粗黑体标题“购买须知”。下方全宽金黄色横条，用非常醒目的黑色粗字写“电子教学资料 · 请先看清内容”。正文为四个编号区块，黑色大字，课题、“希沃课件”、已核数量和格式等重点用红色强调；第二、第三项可以置于浅粉色宽背景。参考密集但清楚的大字通知版式，不使用绿色卡片。所有文字逐字准确、字号足够大、行距清晰、边缘无裁切。

正文逐字渲染如下已冻结文字：
1. 适用课题：〔真实年级学科与课题〕。请先核对课题与教学需要。
2. 资源包含：〔已核PPT课件信息〕、希沃课件及〔实际教学设计、课堂逐字稿、公开课说课稿，可附其已核数量〕；配套课堂学习单和电子版黑板贴。
3. 文件形式：〔实际课件及文稿格式〕；电子版黑板贴提供透明PNG和可编辑PPT。
4. 购买前请查看详情页中的课件与配套实页，确认内容符合您的教学需要。

第2项中的“希沃课件”是用户明确最终提供的资源，保留名称，不补写已上传、分享链接、文件后缀或未知功能。第2、3项的其他资料与格式只保留本课真实存在的内容。未交学习单、电子版黑板贴或可编辑PPT时，出图前由制作者删去对应短语，不由图像模型自行判断或补造。
尤其注意：学习单不写任何数量，电子版黑板贴不写任何数量，不写板书布局数量或“两套板书布局”；名称必须为“电子版黑板贴”，格式名称为“可编辑PPT”，不能出现“可移动PPT”。不要从参考图猜测或补上这些数据。
禁止加入水印、账号、店名、价格、二维码、发货方式、退款条款、原创或售后承诺、赠品声明，以及正文之外的信息。
```

生成后检查的是实际图片，不能只检查提示词。发现漏掉希沃课件、错字、数量回填或旧称呼时定向修订该张，保留旧结果及真实调用记录；其余已核主图和详情不重做。工具实际像素按返回文件记录，不因模板写“高清”声称特定分辨率。

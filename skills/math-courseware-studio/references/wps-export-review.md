# WPS导出视频的用户验收与交接

## 默认交接方式

C8默认采用“用户用WPS手动导出整课视频 → 自行检查并确认无误 → 提供本地文件地址 → AI登记并继续后续步骤”的方式。用户负责检查导出视频中的页面、动画呈现和音画；AI接受其检查结果，不重复审片、听辨、抽帧或建立逐页时间映射，不再要求用户填写整套验收表或再次确认同一结果。

这份整课导出视频是用户已检查的交接文件，与V001等情景视频成片分别登记。它不替换可编辑PPT、原情景视频或互动网页，也不自动成为对外教学产品或宣传视频。

## 用户交什么

1. 从本课当前有效PPT导出覆盖全部页面的MP4，保留动画、转场、内嵌视频及原有声音。静态知识页可无声，无须另录教师讲课旁白；导出时长不要求等于实际课时。
2. 用户自行查看、听播导出视频，确认内容与播放无误后，再把本地文件地址发给AI。已有本课PPT地址和版本直接沿用，只有明确改版或无法绑定来源时才补齐相应信息。

若当前会话已明确约定“检查无误后才发地址”，后续作为最终交接发来的地址可与该约定合并记录为用户确认，不再重复追问“是否检查过”。没有这类约定、只给地址且检查状态不明时，仅补问缺少的检查结论。草稿、尚未检查、请求排查问题或讨论中的路径不能当作已确认交接。

尚未回传时，标为“等待用户检查确认后回传视频”，继续不依赖该文件的已授权工作；“我会检查”是未来安排，不能提前登记尚未收到的视频通过。

## 收到地址后怎样接收

- 只做交接所需的文件检查：路径存在、文件可读取、当前源PPT与回传视频可定位，保存真实路径、版本和SHA256；按实际需要核复制后的字节一致性。这些检查用于接收和版本绑定，不启动视频内容复查、全片解码、音轨分析或自动转写。
- 保存用户真实检查结论及其明确覆盖的范围；沿用会话约定时，同时保存原约定与本次实际交接依据。表述为“用户已检查确认”，不能改写成“AI已完整看听通过”。
- 按现有目录约定接入并更新交付清单、进度与HANDOFF，继续符合前置条件的后续工作。新五目录课可用逻辑路径`editable/returned/playback-vNNN/`，实际在中间文件下；旧课沿原布局，原文件保留。
- 路径不存在、文件无法读取、源版本不明或同名文件已换版时，仅处理具体接收/版本问题，不以此默认重启审片流程。文件实际换版后旧结论不自动套用新版本；沿同一“检查后交接”约定接收新的明确最终版本。

## 用户确认的范围

| 项目 | 可采用的证据与边界 |
|---|---|
| 页面、页序、动画呈现、情景视频音画 | 采用用户对当前导出视频的检查确认；AI不重复核查 |
| 鼠标单击、PPT超链接、网页拖动交互 | 采用已有同版操作证据或用户对这些项目的实际确认；单纯视频确认不扩展为操作通过 |
| 文字/图形独立可编辑、文稿、学习单、黑板贴 | 复用已有同版有效核查；视频交接不触发整套返工 |
| 课堂投影、扬声器、打印效果 | 保留实际已知状态，不能从视频确认推断设备已验 |

用户未提到的项目保持原状态，不从视频推断通过，也不因本次交接自动发起额外实播审查。用户明确确认同版整套检查无误时可记录其实际覆盖的项目，不拆成多轮重复确认；整课是否完成仍按现有范围、实际文件和有效记录判断。

## 实际产物与修订

本步产物是用户已确认的视频接收记录、更新后的交付清单与进度。对用户简短说明已接收及接下来执行的步骤；默认不再生成审片报告、时间点问题表、相同内容的PPT或视频，不增加一次“批准接收记录”的关卡。

只有用户另行要求复查，或提出具体页码/时间点的问题时，才检查指定范围并反馈、修订。此时如实区分AI实际查看/听辨与工具只能抽帧的范围，不把用户检查结果改写成AI复核。

## 与现有工作流记录衔接

默认使用已有`inspection: user_report`，basis保存用户检查确认原话，或“先检查后交接”的原约定与本次真实交接依据；允许附加`evidence_kind: user_confirmed_wps_export`。不为接收流程伪填`inspection: actual`；只有AI另行实际检查的项目才按真实范围记录actual。这些是宿主记录，现有CLI与字段保持兼容。

`source_versions`绑定当前PPT、回传视频以及用户确认实际覆盖的媒体/交付文件。已确认范围可记`passed:true`；仅覆盖视频时不能扩展为全课所有检查通过。正式整课汇总继续采用真实用户回报及已有有效证据，全部适用项齐备才作为已通过的`delivery.files.wps`。

每段视频的`final.files.media`仍指向原实际情景视频，其playback可以引用明确覆盖该段且绑定当前PPT/媒体的用户确认，不强制AI再建时间映射。自动模式H23保留human任务与原七项清单，依据真实用户确认和已有同版记录登记；在“检查后交接”的明确约定下，按收到的具体文件接收，不再追加AI复审任务。`complete`仍核原产物、来源、采用及完整范围，不能从单段/仅视频确认推断全部七项完成，也不补造历史记录。

# 视频与整课衔接

本规范由studio统筹，plan安排教学节点，pages安排播放区域，documents写教师语言，editable处理实际PPT副本。视频总入口及五个专业Skill只负责吸引儿童观看的剧本、图片素材、镜头和视频词，以及授权范围内的实际媒体检查。

## 课程范围与顺序

从头整课至少一段必做情景视频，数量按实际教学任务；局部PPT修正或单独视频不自动扩大范围。课程的故事、数学、原有角色与禁提前揭示的内容作为视频输入约束，不强制每个开场镜头都承担讲题或学生操作。

顺序：分析→共同故事/数学→视频创作与制作准备→逐页PPT（含视频页）。视频内部为剧本/25格预览→实际图片资产→导演→黑白板→固定风格→逐段词。风格选择、封面参考和共享资产可在视频第二步由plan与video-assets衔作，先已有图后必要补图；不能要求等导演/故事板完成才允许制作其依赖的资产。预览可以临时形象起步，不能反过来要求先完成全部三视图。

封面仍按plan的公开课规范制作；已有采用封面/角色图直接复用。视频需要的资产与PPT共享同一已采用版本，不由两模块各画一套同名角色。

## PPT开工前的视频方案检查

在planning/video-handoff.md保存以下具体内容，覆盖全部必做视频，不只一个代表片段。该文件的课程字段由studio/plan填写，不要求video writer产出教师接话。

| 必须具备 | 可核对的成果与负责方 |
|---|---|
| 全课范围 | studio/plan列video_id、教学节点、关联事件/数学、观看任务、预计时长和视频结束状态；不固定片数 |
| 剧本与完整声音 | writer交每段具体可见事件、完整对白/旁白、说话者和声音安排；讲话路线只需完整讲话与持续画面，估时和实测分开 |
| 具体画面与素材 | 讲话首帧及参考的制作方案；运镜路线导演双表、黑白板方案、真实或待制作资产清单及对应完整提示词；有实图则链接当前版 |
| 全部片段操作 | prompts给全套逐段完整词、实际参考职责及用法；未知平台字段明确待配置，不能只列通用工序名 |
| 制作流程与缺项 | 对应路线的图片、数字人/生成片段、声音、必要剪辑及媒体检查安排；缺哪张图/哪项工具、由谁怎样补、影响什么 |
| 课程衔接 | plan/pages定预留页数、播放位置/画幅、播放前观察任务；documents在课程记录写片尾教师接话/下一活动；未排页不编page_id |
| 依据与审阅 | 当前文件/版本/哈希、逐项核对和真实确认依据，复用视频两组审阅及已有同版确认，不另把每张表设一道重复审批 |

只有video_nodes摘要、素材清单或一个小样操作包不通过。未知平台不妨碍具体内容方案；缺图时如已完成完整文字方案及取得办法，可记录“方案完整、实图待制作”，据实继续具备条件的课件工作，不能说六步实物交付已完成。PPT页面生图仍需其引用的真实采用资产。剧情/声音/镜头仍空缺时先补准备内容再排逐页稿。

方案准备通过与成片通过分开。实际成片可与PPT制作并行，必做待办保留。用户明确只修改Skill时不重做历史课件或代填课程确认。

## 回填和最终完成

1. video交实际成片、媒体属性、最终逐字稿、结束状态和真实检查；未取得文件或未看听的项目保持待查。
2. 若成片改变共同事件、数学或台词含义，先由plan核准并保存共同记录的新版本，再同步引用页面和文稿；不修改正确题目来迁就生成错误。
3. pages为每个独立播放节点安排计入总页数的视频页，video_ids与真实page_id/order对应，播放区域独立可编辑且不被文字遮挡。现有验收页需变动时给具体调整稿，按当前授权执行，保留旧版。
4. editable在实际PPT工作副本中插入视频或按用户已选方式关联，核对实际媒体对象、声音、画幅和播放方式。仅填路径、画按钮或复制视频不表示已嵌入。
5. documents按最终采用版更新教师逐字稿、说课稿、教学设计；教师话与视频音轨分开。未锁定页面只能写相关段落草稿，不编逐页定稿。
6. 记录WPS/实际环境的播放证据；工具结构校验不能代替现场播放。汇总课件collect和视频明确文件清单，collect本身不收视频。

只有全部必做成片、视频页与实际播放、三文稿对应均核对后才称整课完成。占位页、静态图、教师代读或collect成功不替代成片；缺成片可以交“静态阶段稿（视频待回填）”。不由视频创作Skill负责课堂接话，不等于课程省略衔接。

# 正式黑白板的生图提示词规范

实际执行时由AI填完整，不让用户从导演表手动拼接。仅当用户要求模板或实际输入未到时保留明确标注的缺项；这种文本属于准备稿，不称为可执行的完整制作包。

## 输入提取

从导演静态表提取：镜号、镜头功能、构图、画面描述、景别、机位、镜头角度、焦段感、运镜与视觉规则。只把其中决定画面的内容写入各格描述；运镜作为规划或必要示意，不要求在一个静帧里表现一整段运动。

同时登记：视频/导演版本、实际镜头数、关键帧数、每格画幅、实际参考图片和用途。角色/场景多视图是外观和空间设定，不能把拼图的三个视角画成三个剧情人物或新增镜头。

区分真实缺输入与可自行决定的执行细节。缺角色实图不能假装已有；仅缺左右手选择时，在现有姿势、道具和构图允许的前提下由AI选定并记录，确保相邻镜一致，不因此新增用户确认。若某只手已有道具或决定剧情，则服从来源，不能当成可任意选择的细节。摄影机方向属于导演设计，必要时由AI补全相邻导演记录；无需把这类专业判断一律交给用户。

## 提示词固定组织

```text
【任务与范围】
根据已确定的分镜图生成列表，绘制正式黑白故事板。
视频与导演版本：填写当前真实记录。
本板包含的镜号与关键帧ID：逐一列出。
共几镜、几格：依据正式表填写，不从秒数或25格预览推定。
严格保持镜头内容、顺序、人物和事件，不自行增加、删减或合并。

【参考图片职责】
按本次实际输入逐张写清：文件/引用标签、角色/场景/道具用途、
采用的视角及必须保持的特征。实际没有图片时不写“已上传”。
多角度图只作为同一角色/环境的设定依据，不复制其拼图排版、
文字标签或多个人物副本，不把场景设定图固定当作某镜构图。

【画面与排版】
使用清晰黑白线稿与适量灰阶，主体、前中后景和空间可辨。
保留参考中的角色身份、服装轮廓、设施结构和比例。
每个镜框采用既定视频画幅；整张板按实际格数安排，优先保证
各格可读。末行可不铺满，不通过重复镜头或新增画面填满网格。
按阅读顺序排列，镜号清楚标在框外或边缘，不遮人物与动作。
只画正式镜头，不加底部参考图、色卡、三视图、站位图或大段说明。
不在画面中生成对白气泡、字幕、教学题目或摄影器材参数。

【空间与连续性】
填写已确定的人物左右、前后距离关系、视线目标、运动方向、
相邻镜的物体状态和身份特征。用关系描述，不虚构精确距离。
同一主体保持同一形象；数量与结构服从已确认输入。
场景转换按导演表，不为了“连续”把不同地点画成同一空间。

【逐格画面】
对每一正式镜号逐一填写：
镜号/关键帧ID；这格取动作的哪个关键状态；景别；机位和角度；
构图；实际可见的人物、姿态、道具、背景与位置。
同一角色只出现该时刻的一份身体，不用分身表示前后动作。
完整复述各格需要的内容，不写“同上”让模型猜测。

【必要的运动示意】
仅对确需提示方向的格子使用少量简洁箭头。
摄影机运动与人物/物体运动采用可区分的标记，说明放框外，
不把箭头画成故事中的实物。方向以导演记录为准，不增加运镜。
若静态构图已足够清楚，可不画箭头。

【输出】
输出一张包含上述全部正式镜号及必要关键状态的完整黑白故事板图片。
若制作时逐格出图，单格为中间素材，核查后仍须整理为实际整板。
黑白仅是本板的构图表达，
后续视频色彩与材质另用已采用彩色参考及固定风格说明。
```

这里“不能把场景设定图固定当作某镜构图”用于多参考绘图；若用户已明确指定某张实际首帧或某镜构图，则保留该指定，不用通用规则推翻用户选择。

实际图片生成后填写真文件和逐格观察。只写提示词时记录计划映射与未生成状态，不创造空图片或伪路径。

逐格制作后，由AI按顺序合板并复核人数、结构、方向和画幅，原单格保留。网页并排展示不是实际整板文件；合板后更新映射、上传表和完整视频词，具体按[整板上传规则](../../math-courseware-video-prompts/references/prompt-assembly.md#整板上传默认必须执行)。

一镜多关键帧时，例：V01-S02a为纸鸟接近、V01-S02b为将落下；必须来自导演表的明确映射，不由故事板模块自行拆分。两格合属一镜，视频词仍引用该镜一次并表达连续动作。

## 排版和修订判断

- 13镜、25格、某个横竖比都不自动成为正式板约束。以本段实际镜头和成片每格比例为准。
- 借鉴第25期清楚的镜号、独立镜框、灰阶构图和少量箭头，不机械照抄其最后一格跨整行的长宽比。
- 第18期的人物站位和环境结构有助于检查空间，放在制作记录或独立空间参考；不要求在正式板底部重画这些图片。
- 真实输出或实际上传压缩后的格子看不清时，先减少板内文字、提高可用分辨率；仍不足再按连续镜号分成少量清楚的板，并记录具体检查依据与各板范围，不默认逐格上传。片段分配不自动等于分板，更不固定每15秒重绘。
- 若实际生成时文字镜号有误，修正标记并再次核对画面对应，不仅在说明中悄悄换编号。改图沿当前授权的图像编辑工具执行。
- 图片内部核对通过与用户采用分开；构图正确与真实运动/声音表现分开，不以静态板宣布成片稳定。

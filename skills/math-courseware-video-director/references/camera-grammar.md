# 镜头方法与选择

先明确事件、观众关注点与当前变化，再选方法。下表是可选择的方法库，不是每条必须用一次的清单。

| 需要解决的问题 | 可用方法 | 要在镜头里写出的具体内容 | 自检 |
|---|---|---|---|
| 想让观众一起发现新事物 | 视线引导、先反应后揭示、局部到整体 | 谁注意到了什么；第一眼能见什么；对象何时显露 | 揭示有明确对象，反应有由来；不要强制每段都先拍脸 |
| 观众还不清楚环境或关系 | 全景建立空间、由主体运动带出环境 | 主体在何处、与关键设施是什么关系，随后转向哪个焦点 | 环境镜头能提供新信息或体验；不因为是空镜就一律删除 |
| 画面平、人物像排队摆拍 | 前中后景分层、错开的反应、遮挡后揭示 | 谁是主焦点；谁在后景；动作怎样有先后 | 背景热闹不能抢走主事件，也不强塞新角色 |
| 主体在运动 | 跟拍、平行移动、固定机位让主体经过 | 跟随哪个主体、保持怎样距离、从何处移动到何处 | 物体移动与摄影机移动分开写；不是每个运动主体都要跟拍 |
| 想从细节进入整体或发现隐藏内容 | 推进、拉远、横移揭示 | 运动前看见什么、途中新增什么、在哪里停 | 删掉运镜是否会损失观看信息/体验；若不会，简化 |
| 想表现空间或设施各面 | 有目标的局部环绕 | 围绕哪个对象、途经哪些可见事件、起止朝向 | 不默认360度；空间一致且途中确有内容变化 |
| 一段动作显得急或拖 | 建立→动作→反应；不同镜长对比 | 哪个动作需要看清、哪里可以快、哪里应停留 | 不按每秒切镜；不把“活泼”自动翻译成全程快切 |
| 两镜连接生硬 | 动作接续、视线接续、形状/方向关联、声音先行 | 上镜结束状态、下镜开始状态、采用哪个联系 | 无需所有切换都做花哨转场；不强求不相干地点是连续空间 |
| 观众分不清位置或运动方向 | 保持同侧空间、明确建立新视点 | 人物左右、视线目标、运动方向；换侧时怎样交代 | 不镜像复制参考造成设施左右颠倒，机位变化应能解释 |
| 无对白但想引起注意 | 事件音效、画外声音提示、可见人物反应 | 声源是什么、何时出现、画面怎样回应 | 不把“无BGM”误作全片静音；不凭空新增台词 |

## 每镜的六个问题

1. 观众第一眼看哪里？
2. 这一镜具体发生什么，和前一镜相比有什么变化？
3. 这个景别、机位和构图为什么适合这件事？
4. 如果运镜，摄影机在哪里开始、跟随/揭示什么、在哪里停止？如果静止，画面内如何表演？
5. 动作与对白能在预计时长内完成吗，最后留下什么状态？
6. 与下一镜通过什么关系接上？可以是直接切换，无需强造连续动作。

## 小例子

输入事件：一只折纸鸟飞来，女孩伸手，纸鸟落在手指。可先用中景交代女孩的注视和纸鸟位置，再用全景保持飞来方向，最后以手部近景显示落下的结果。小幅横移是为了跟随纸鸟并保留接近关系；最后静止让落指动作完成。无需增加环绕、撞击、故障或新的追逐情节来制造“趣味”。

如已定导演表规定另一个镜头数量/顺序，故事板环节不得按本例重写。方法库用于导演选择，不取代具体输入。

## 来源边界

发现与人物反应、长镜头内构图变化、群像层次、运动揭示和声音先行来自用户所给v3规则卡的可复用思想；儿童体验、动作完成性、明确起止与应用自检为本项目整理。不是某位导演的唯一拍法，不把所列方法当作保证吸引注意的公式。

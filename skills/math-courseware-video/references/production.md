# 视频制作与检查

本页是总入口的执行说明，详细创作格式分别维护在专业Skill，避免多个版本互相覆盖。

## 六步推进

1. [编剧](../../math-courseware-video-writer/SKILL.md)：先完整script/voice在聊天逐场逐句审查并采用，再做适用25格预览；固定讲话同样先审文字但不用25格。起稿不依赖全套设定图。
2. [资产](../../math-courseware-video-assets/SKILL.md)：剧本和预览通过后复用/补齐正式角色、场景、重要道具；确认参考外观并整理风格初稿。用户反馈已包含采用时复用，不重问。
3. [导演](../../math-courseware-video-director/SKILL.md)：先安排节拍与空间，再设计静态构图和动态镜头，完整输出八部分双表。新素材需求只回补相关资产。
4. [故事板](../../math-courseware-video-storyboard/SKILL.md)：从静态表与实图制作正式黑白板，逐镜检查。镜头设计变更先更新两表，再修相关板格和视频词。
5. [资产固定风格](../../math-courseware-video-assets/SKILL.md)：以实际采用彩色图为依据冻结段落；黑白板不决定成片色彩。各片段沿用同一段原文，光线的剧情变化另写。
6. [视频词](../../math-courseware-video-prompts/SKILL.md)：从动态表组装声音、参考职责、风格、镜号范围、逐镜内容五部分，附真实上传映射和完整用法。长板可以供多个片段选镜号复用。

固定讲话在完整文字实际采用后连续准备首帧、完整TXT和操作包，不因模块切换拆步确认，不加导演/切镜。合格同版旧图复用；平台实限确需调整完整台词时说明依据，不静默删句。

## 4. 自动制作实际素材

此标题保留旧链接兼容；当前六步中的资产为第二步，正式板为第四步。

需求与线路明确后，由对应专业模块写完整提示词、关联真实参考、调用可用生图工具、查看输出并针对性修正；总入口收齐普通文件夹。已有同版实际图直接复用。视频平台由用户自行选择，不主动提问；未提供也按[通用制作包规则](../../math-courseware-video-prompts/references/prompt-assembly.md#通用素材包与平台适配边界)完成角色、场景、预览、黑白板及第六步的完整逐次视频TXT和建议上传映射。具体按钮、标签和兼容性未核如实标注，不能因此只交半份内容。

工具不可用、输入确实不足或仅授权文字时，保存可执行准备稿及具体缺项：哪张图、为什么缺、哪个下游受影响、由AI如何续作。不能把任务已提交当作文件已收到，不能只给提示词便标记素材齐备。参考与结果都需实际查看，不能从文件名或提示词臆测图像。

## 从视频提示词到实际媒体

素材流程负责完成具体图片与文字，不代表自动消费视频/配音额度。用户要求素材包时完成到该范围；用户继续要求成片时再按已有授权、工具与平台实际能力推进。

- 平台能力：核对实际入口支持的参考类型、引用标签、声音方式、画幅和时长；记录日期与官方资料或用户真实界面。未知保持待配置，不编造可提交参数。
- 生成片段：按动作、完整台词长度及实际平台限制安排。镜头S、一次生成C、最终播放视频V是不同层级，不能因视频模型单次上限就删剧情。
- 按已授权范围生成并交付片段，记录实际任务ID、引用、输出、费用/耗时；未知就写未知。成片由用户人工检查，不自行新增代表片段审片或先验后批量的额外环节。
- 状态不明先查已提交任务，避免重复付费；同类错误重复出现时改变方法，不机械重试。平台确不支持多格参考或实际小样混淆时，可针对需要改用独立关键帧，记录原因，不预先重画全部镜头。
- 制作剪接方案时依据既定导演与对白安排衔接，普通切镜不强求首尾帧锁定；实际片段的动作、声音和衔接效果交用户人工检查。用户另行委托AI剪辑或专项分析时按该次明确范围执行。

## 实际成片检查

本节保留旧链接，成片验收由用户人工执行。AI交付真实片段/成片及任务、文件、版本信息，核可访问性并接收用户反馈；不主动看听、抽帧、分析音轨或创建审片报告。

未取得人工结论时写“待用户人工检查”。用户反馈通过或具体问题后，按实际文件、版本、哈希保存原话及确认范围，已有同版确认直接复用。人工检查结果与AI读取的技术属性分别记录，未知项不补成已验证。

用户指出问题时按具体事实定位到剧本、导演、资产、故事板或提示词，沿当前授权修订。用户明确要求AI分析某片时再处理该次范围。既有教学条件、黑白分镜选择及费用边界仍有效。

## PPT开工前的视频方案检查

这是兼容旧链接的入口。课程是否可进入PPT、教师接话、页数预算和成片回填的当前规则统一由[studio视频衔接](../../math-courseware-studio/references/video-integration.md)维护；不是视频专业模块的创作交付。

# 黑板贴：同款电子版与实尺寸打印版

整课C7默认随三份文稿一起制作黑板贴；新制整套黑板贴默认**电子版＋同款实尺寸打印版一起交付**，不等用户另行提出打印需求，除非用户明确只要电子版或省略打印。只做文稿、局部修订或其他独立任务不自动扩大范围；用户单独要整套黑板贴时，核对有效课件即可开始，不要求重做视频或三份文稿。新制作默认已确认的**楷体彩边**：楷体黑字、白色衬底、彩色圆润云朵轮廓，外部透明。用户明确选择的其他字体/样式优先，不重新询问已定偏好，也不因默认更新改动已完成的旧课程。

## 1. 先由AI决定要做什么

读取当前有效PPT全页及教学设计中的板书，必要时核对逐字稿。列出课题、核心概念、典型例子、关系箭头、关键数量图、名称标签、归纳语和必要的练习空卡。每件记录教学用途、来源页和实际文字/数量。参考截图只借鉴视觉，不继承其错误结论、数字或固定乘数顺序。

按课堂形成知识的顺序组织整板：初步发现、理解方法、辨析/迁移按本课需要合并或分板。不要复制全部PPT，也不固定为59件或3板；不加入课中未教的公式、例题和教学大环节。学生应自己归纳的内容可以留空卡，答案贴独立保留，注明何时出现。先在项目中保存`design.md`说明取舍和内容对应，不让用户逐件指定怎样画。

## 2. 默认楷体黑字、白衬和彩色圆润轮廓

| 内容 | spec中的role / kind | 默认字体与外观 |
|---|---|---|
| 课题 | title / word | 楷体黑字、白衬、金黄外轮廓 |
| 短关键词、概念说明、数量关系 | display 或 explanation / word | 同一楷体黑字、白衬，青色外轮廓为常用选择 |
| 读法 | reading / word | 同一楷体黑字、白衬、金黄外轮廓 |
| 名称标签、归纳语 | explanation / word | 同款字形轮廓；按层次选粉、金黄或紫色，不默认实心胶囊 |
| 算式 | card | Arial数字/运算符、楷体单位，黑字白衬蓝色圆润轮廓；分数上下排列，横线有圆润端帽，不用矩形底框 |
| 连接箭头 | arrow | 黑色实心箭头、白衬和彩色圆润外边，首尾闭合包边完整 |
| 括线、空卡、数量图 | brace / blank / dots | 保持数学含义的程序图形，数量来自课件；不把图形改成装饰字 |

角色、椅子等已有素材优先复用为`image`，保留来源哈希及透明安全边距。生图适合补必要插画；精确文字、算式、标签不交给生图模型随机重画。复杂几何图需另按数学要求制作和检查后作为`image`接入，不能用点阵冒充。

默认中文各role及单位均读取现有`KaiTi`（Windows的`simkai.ttf`），算式读`Arial`；不能只改颜色、仍用原快乐体/麦圆体或雅黑冒充楷体。程序检查实际文件、版本哈希和缺字；缺字体时报告并定位已有字体，确需替代时明确说明并检查样张，不悄悄替换。`spec.fonts`按role指定的实际文件优先。包内三款开源字体及许可仍见`assets/blackboard/font-sources.json`，供明确选择的其他风格或替代使用，不再默认混搭。系统字体只读取，不安装、不复制到Skill或成品中。

默认字色`#050505`、白衬`#FFFFFF`，外边金黄`#E7B34C`、青`#1CB6BE`、蓝`#65A5E4`、粉`#E88FA6`、紫`#A28AD0`。颜色只区分层次，不额外赋予数学含义；素材本层`color`可选`yellow/gold`、`teal`、`blue`、`pink/rose`、`purple`。中文白衬半径约字号的10.7%、彩边约19.7%；保持楷体原笔画，不把字填成黄字或做模糊发光。衬底随字形连续起伏，保留字内白色孔洞，不能退回矩形算式框或实心胶囊替代默认云边。只有用户或教学内容明确需要椭圆/胶囊底板时才选`pill`，其真实字形安全检查仍执行。

## 3. 标签必须验证真实字形的安全区

不能只比较文字外接矩形与椭圆宽高。程序先绘制实际字形蒙版，再检查**所有字形像素均在底板向内收缩的轮廓中**：安全内缩至少14像素或底板高的8%，未通过就扩大底板重算。单字圆牌、双字椭圆、长句胶囊都执行，不只修“乘数”一项。

整板默认2000×1125，标签可见字高不得小于22像素；根据课堂阅读距离宜更大。不得通过降低阈值、压扁图片或将错误重叠声明为有意重叠来绕过检查。词牌与其他文字仍须查看整板可读性。名称应对齐所指算式项，括线只括相同加数部分；用算式锚点定位，不靠猜中心位置。

## 4. 数据清单与执行

内部新增`assets/blackboard-plan-vNNN/`保存来源索引、`design.md`和`spec.json`；成品放新的`assets/blackboard-vNNN/`。先在本课AGENTS约定目录和命名。渲染器拒绝覆盖已有成品目录；失败记录保留，修订用下一版本。对外文件和文件夹用中文，普通目录交付，不自动ZIP。

`spec.json`由AI维护，用户无需写JSON。最小示例（哈希用实际源文件SHA256替换）：

```json
{
  "title": "平均分",
  "sources": [{"id":"lesson","path":"../../inputs/lesson.pptx","sha256":"<实际SHA256>","page_count":7}],
  "assets": [
    {"id":"title","name":"课题平均分","kind":"word","role":"title","text":"平均分","color":"yellow","source_refs":[{"source_id":"lesson","pages":[1]}],"purpose":"揭示课题"},
    {"id":"concept","name":"每份同样多","kind":"word","role":"explanation","text":"每份同样多","color":"teal","source_refs":[{"source_id":"lesson","pages":[3]}],"purpose":"比较分法后归纳"}
  ],
  "boards":[{"name":"核心板书","notes":"比较每份数量后贴出概念。","items":[{"id":"title","box":[400,60,1200,180]},{"id":"concept","box":[450,440,1100,200]}]}]
}
```

路径相对spec文件，sources必须是已核对的真实输入；页码是该输入实际页码。语义素材均需`source_refs`和`purpose`。`color`与`role`放在素材本层，不能重复放进`params`；未知参数会在输出前被拒绝。支持参数：

- `word`: `size`（默认240）；role决定字体，课题role为title。
- `pill`: 仅用于明确需要底板的标签；`size`（默认210）、`oval`（默认false），自动安全留白。
- `card`: `size`（默认190）、`unit`；数字/运算符不必加空格。`3/4=75%`中的分数按分子、横线、分母绘制；`5/10`配`unit:"米"`完整保留单位，不擅自加括号或换成百分号单位。text使用真实`×`，不使用字母x。简单行内分数以外的复杂数学仍需精确另制并走`image`接入，不能退回斜线字串或生图重画。
- `dots`: `groups`、`count`，或`different`逐组数量数组。必须核对实际点数与分组含义。
- `blank`: `width`、`height`；`arrow`/`brace`无参数。
- `image`: `source`、`sha256`、`padding`（默认16）；提供已有透明PNG。

`boards[].items[].box`是像素`[x,y,w,h]`，素材保持比例居中放入。需要精确标注时，先放算式并可设`instance_id`，名称标签用`anchor:{"target":"算式的instance_id或id","token_index":0,"height":80,"gap_y":12}`；token_index为算式数字或运算符从0起的序号。括线用`brace_for:"算式的instance_id或id"`。引用目标必须先出现。只在有教学意义的真实叠放时写`intentional_overlap`原因，普通碰撞必须改坐标。

先发现已有运行时，检查渲染环境有Pillow/fontTools，导出环境有Pillow/python-pptx/ReportLab/pypdf；可用两套已存在的环境分别执行，缺依赖不自动装到全局。命令在总入口包内，不依赖原乘法课目录：

```text
<渲染Python> scripts/runtime/blackboard.py render --spec <spec绝对路径> --output <全新版本目录>
<文档Python> scripts/runtime/blackboard.py export --project <该版本目录>
<文档Python> scripts/runtime/blackboard.py verify --project <该版本目录>
```

这是独立的真实入口，不是`courseware.py`的子命令。不存在`workflow-check --step blackboard`。整课C7文稿仍按`documents`核前置；仅黑板贴按本节核来源，不能据黑板贴完成把三份文稿登记完成。

## 5. 检查与交付

先完成程序检查，再查看每张整板实际图片和PPT渲染；普通问题直接改下一版本，不增加重复审批。验看内容/来源、数量/单位、语义正确、实际楷体文件、缺字、黑字白衬/五色轮廓、字内孔洞、分数线两端和箭头闭合首顶点的完整包边、底板留白、整体字号、公式名称对齐、括线范围、重叠和页面边界。默认名称/概念应为同款字形轮廓，不能混回旧实心标签；精确字图不交生图。程序自动核简单非负整数连加/连乘等式；其他算式与推理需人工核算，不能把分数已画成上下格式当作关系已验正确。课堂硬件投屏与静态渲染状态分开记录。

每套电子部分至少交：全部独立透明PNG、逐件可移动PPTX、同序布局参考PDF、整板PNG、离线素材总览、使用说明、文字源清单；同时交下节规定的实尺寸打印部分。PPT是各贴纸独立PNG对象，可拖动/复制/缩放，**字形不是原生文字**；改字要改spec再渲染。布局PDF仅供排板参考，不能替代打印裁剪稿。

## 6. 默认随套交付实尺寸打印版

从本次同一版字形和内容制作，保留楷体黑字、白衬、彩边、上下分数和单位。先定每件用于黑板展示的成品宽×高，以毫米排版、厘米说明；依据课题/关键词/概念/算式的字数和阅读需要确定尺寸，图片等比放置，不压扁、拉长或把整板缩小代替独立字条。长句可按语义分条，合起来逐字不变，并保留原素材与分条编号的对应；件数、尺寸及页数按本课计算，不套用示例课的固定数量。

- **纸型与拼接：**默认推荐A3横向（420×297mm），同时提供A4纵向（210×297mm）备选。A4裁接后的每件成品与A3相同大小，能单页容纳的无需拼接，跨页的保留10mm重叠及清晰的配对编号、裁切/对齐标记；按可打印区域计算分页，不能机械把A3切两半。四边至少留10mm打印安全边距，裁接标记不得压住字形和彩边。
- **实际文件：**交A3原尺寸PDF、A4同尺寸PDF（需跨页则命名“同尺寸拼接版”）、打印说明与完整成品尺寸表、全部打印页预览。尺寸表列素材/分条编号、文字、成品宽高和所在纸型页码，交付入口分清电子布局参考与实际打印稿，两种纸型二选一即可。
- **打印操作：**明确对应纸张及方向、彩色单面、一纸一页、100%／实际大小，关闭适应纸张和自动缩放。每页提供100mm校准线；说明先打印一页用尺核对10cm，裁后沿编号/对齐线拼接，再剪外轮廓贴黑板。不要让用户自行猜纸型、尺寸或缩放比例。
- **清晰度与核查：**按成品物理尺寸核有效DPI，目标不低于300；不足时从原生字体/几何提高渲染精度，不只改DPI标签或放大旧栅格。核PDF实际纸张尺寸、所有素材/文字/单位覆盖、成品宽高、A3与A4等尺寸、重叠区域及裁后完整性，实际渲染查看全部打印页，确认无裁字、压边、重叠和丢件。记录实体试印状态，数字核验通过不能写成已实体试印。

现有`blackboard.py export/verify`只导出和核电子版及布局PDF，**不包含实尺寸打印分页或打印验收**；按上述尺寸计划另行生成并核查打印文件，留实际来源、排版数据与结果，不编造不存在的打印CLI，也不能据电子版verify通过标记整套交付完成。本分支不自动更新商品图、商品介绍或笔记，也不改原课件。

`content.json`保留来源、字体哈希、每件参数、标签安全检查和实际尺寸；`layout.json`保留摆放；`manifest.json`/`verification.json`记录成品与检查。视觉核查另保存实际预览和结果，程序通过不等于视觉已采用。源课件改版时重核受影响内容，不只刷新哈希。将当前实际结果和缺项写入HANDOFF。

当前`collect`不自动收这套额外文件。交付时按电子版及打印版的实际manifest，将已核成品复制到与课件配套相同位置的中文普通文件夹，打印部分放其下“打印版”，逐文件核哈希。聊天同时给电子入口、打印PDF与说明直链，明确推荐哪种纸、各几页、成品尺寸在哪查看及100%打印要求。整课C8必须额外核对两部分均已交付，或存在用户明确省略依据；打印仍未生成或未核完时不得把整套黑板贴记为已交付，控制器的`complete`通过不能替代这一检查。不复制内部字体、私有来源或测试夹具。

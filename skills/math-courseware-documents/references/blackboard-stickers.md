# 电子黑板贴：按课选择，固定绘制，逐板验看

整课C7默认随三份文稿一起制作电子黑板贴，除非用户明确省略。只做文稿、局部修订或其他独立任务不自动扩大范围；用户单独要黑板贴时，核对有效课件即可开始，不要求重做视频或三份文稿。沿用已认可的字体与样式，不再让用户从头选一遍；用户的新要求优先。

## 1. 先由AI决定要做什么

读取当前有效PPT全页及教学设计中的板书，必要时核对逐字稿。列出课题、核心概念、典型例子、关系箭头、关键数量图、名称标签、归纳语和必要的练习空卡。每件记录教学用途、来源页和实际文字/数量。参考截图只借鉴视觉，不继承其错误结论、数字或固定乘数顺序。

按课堂形成知识的顺序组织整板：初步发现、理解方法、辨析/迁移按本课需要合并或分板。不要复制全部PPT，也不固定为59件或3板；不加入课中未教的公式、例题和教学大环节。学生应自己归纳的内容可以留空卡，答案贴独立保留，注明何时出现。先在项目中保存`design.md`说明取舍和内容对应，不让用户逐件指定怎样画。

## 2. 固定语义字体和样式

| 内容 | spec中的role / kind | 默认字体与外观 |
|---|---|---|
| 课题 | title / word | 站酷快乐体；黄字、深色细边、白边、粉色外边 |
| 短关键词 | display / word | 荆南麦圆体；深色字、白内边、彩色外边 |
| 说明、数量关系、归纳语 | explanation / word | 霞鹜臻楷GB；同款描边，蓝/黄按板书层级使用 |
| 读法 | reading / word | 微软雅黑粗体；黄色描边 |
| 名称标签 | explanation / pill | 霞鹜臻楷GB；粉/黄椭圆或胶囊底板 |
| “读作”等短底板 | reading / pill | 微软雅黑粗体；黄色胶囊 |
| 算式 | card | Arial数字/运算符＋微软雅黑单位；浅底蓝/黄框 |
| 箭头、括线、空卡、数量图 | arrow / brace / blank / dots | 程序绘制，图形数量来自课件 |

角色、椅子等已有素材优先复用为`image`，保留来源哈希及透明安全边距。生图适合补必要插画；精确文字、算式、标签不交给生图模型随机重画。复杂几何图需另按数学要求制作和检查后作为`image`接入，不能用点阵冒充。

包内三款开源字体及许可见总入口`assets/blackboard/font-sources.json`。系统字体只读取，不随成品分发、不安装。程序检查实际文件、版本哈希和缺字；缺字体时定位已有字体，确需替代时明确说明并检查样张，不能悄悄换字形。`spec.fonts`可指定实际字体文件，用户已认可的其他字体优先。

描边、字距和颜色由共用程序固定：正文白边10.8%字号、彩边9.4%、白内边5.8%、字形加粗0.8%；粉`#EB7CA8`、蓝`#43BCE5`、黄`#F3CF51`、深色字`#15212B`。保留字内白色孔洞，不做成模糊发光字。教学内容页不受课件封面画风强制套用。

## 3. 标签必须验证真实字形的安全区

不能只比较文字外接矩形与椭圆宽高。程序先绘制实际字形蒙版，再检查**所有字形像素均在底板向内收缩的轮廓中**：安全内缩至少14像素或底板高的8%，未通过就扩大底板重算。单字圆牌、双字椭圆、长句胶囊都执行，不只修“乘数”一项。

整板默认2000×1125，标签可见字高不得小于22像素；根据课堂阅读距离宜更大。不得通过降低阈值、压扁图片或将错误重叠声明为有意重叠来绕过检查。词牌与其他文字仍须查看整板可读性。名称应对齐所指算式项，括线只括相同加数部分；用算式锚点定位，不靠猜中心位置。

## 4. 数据清单与执行

内部新增`assets/blackboard-plan-vNNN/`保存来源索引、`design.md`和`spec.json`；成品放新的`assets/blackboard-vNNN/`。先在本课AGENTS约定目录和命名。渲染器拒绝覆盖已有成品目录；失败记录保留，修订用下一版本。对外文件和文件夹用中文，普通目录交付，不自动ZIP。

`spec.json`由AI维护，用户无需写JSON。最小示例（哈希用实际源文件SHA256替换）：

```json
{
  "title": "平均分",
  "sources": [{"id":"lesson","path":"../../inputs/lesson.pptx","sha256":"<实际SHA256>","page_count":7}],
  "assets": [
    {"id":"title","name":"课题平均分","kind":"word","role":"title","text":"平均分","color":"pink","source_refs":[{"source_id":"lesson","pages":[1]}],"purpose":"揭示课题"},
    {"id":"concept","name":"每份同样多","kind":"pill","role":"explanation","text":"每份同样多","color":"yellow","params":{"oval":false},"source_refs":[{"source_id":"lesson","pages":[3]}],"purpose":"比较分法后归纳"}
  ],
  "boards":[{"name":"核心板书","notes":"比较每份数量后贴出概念。","items":[{"id":"title","box":[400,60,1200,180]},{"id":"concept","box":[450,440,1100,200]}]}]
}
```

路径相对spec文件，sources必须是已核对的真实输入；页码是该输入实际页码。语义素材均需`source_refs`和`purpose`。`color`与`role`放在素材本层，不能重复放进`params`；未知参数会在输出前被拒绝。支持参数：

- `word`: `size`（默认240）；role决定字体，课题role为title。
- `pill`: `size`（默认210）、`oval`（默认false）；自动安全留白。
- `card`: `size`（默认190）、`unit`；text使用真实`×`，不使用字母x。
- `dots`: `groups`、`count`，或`different`逐组数量数组。必须核对实际点数与分组含义。
- `blank`: `width`、`height`；`arrow`/`brace`无参数。
- `image`: `source`、`sha256`、`padding`（默认16）；提供已有透明PNG。

`boards[].items[].box`是像素`[x,y,w,h]`，素材保持比例居中放入。需要精确标注时，先放算式并可设`instance_id`，名称标签用`anchor:{"target":"算式的instance_id或id","token_index":0,"height":80,"gap_y":12}`；token_index为算式数字或运算符从0起的序号。括线用`brace_for:"算式的instance_id或id"`。引用目标必须先出现。只在有教学意义的真实叠放时写`intentional_overlap`原因，普通碰撞必须改坐标。

先发现已有运行时，检查渲染环境有Pillow/fontTools，导出环境有Pillow/python-pptx/ReportLab/pypdf；可用两套已存在的环境分别执行，缺依赖不自动装到全局。命令在总入口包内，不依赖原乘法课目录：

```text
<渲染Python> scripts/runtime/blackboard.py render --spec <spec绝对路径> --output <全新版本目录>
<文档Python> scripts/runtime/blackboard.py export --project <该版本目录>
<文档Python> scripts/runtime/blackboard.py verify --project <该版本目录>
```

这是独立的真实入口，不是`courseware.py`的子命令。不存在`workflow-check --step blackboard`。整课C7文稿仍按`documents`核前置；仅黑板贴按本节核来源，不能据黑板贴完成把三份文稿登记完成。

## 5. 检查与交付

先完成程序检查，再查看每张整板实际图片和PPT渲染；普通问题直接改下一版本，不增加重复审批。验看内容/来源、数量/单位、语义正确、缺字、描边孔洞、底板留白、整体字号、公式名称对齐、括线范围、重叠和页面边界。程序自动核简单非负整数连加/连乘等式；其他算式与推理需人工核算，不能把未覆盖的表达式当作已验正确。课堂硬件投屏与静态渲染状态分开记录。

每套至少交：全部独立透明PNG、逐件可移动PPTX、同序布局参考PDF、整板PNG、离线素材总览、使用说明、文字源清单。PPT是各贴纸独立PNG对象，可拖动/复制/缩放，**字形不是原生文字**；改字要改spec再渲染。PDF是整板布局参考，不冒充按实际尺寸分页的打印裁剪稿。

`content.json`保留来源、字体哈希、每件参数、标签安全检查和实际尺寸；`layout.json`保留摆放；`manifest.json`/`verification.json`记录成品与检查。视觉核查另保存实际预览和结果，程序通过不等于视觉已采用。源课件改版时重核受影响内容，不只刷新哈希。将当前实际结果和缺项写入HANDOFF。

当前`collect`不自动收这套额外文件。交付时按黑板贴manifest复制`output/`到与课件配套相同位置的中文普通文件夹，逐文件核哈希。整课C8必须额外核对本套黑板贴已经交付，或存在用户明确省略依据；控制器的`complete`通过不能替代这一检查。不复制内部字体、私有来源或测试夹具。

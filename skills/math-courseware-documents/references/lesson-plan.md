# 小学数学教学设计

依据用户给出的《K12教案设计规范》作小学数学适配；它是用户资料，不调用任何被禁用的同名K12 Skills。

## 内容

结合锁定课件写教材/内容分析、学情、目标、重难点、教法学法、准备、教学过程、作业/拓展、板书与反思。未知教材页码、课标原句、班情数据不编造，基本信息里无依据的行省略。

目标、活动、评价对应：学生要理解什么、怎样操作或表达、教师凭什么知道学会了。数学重点写概念形成、例题与变式链、易错点、板演、数学思想和分层支持。

每个关键环节说明教师如何启动问题、追问和组织，学生实际做什么和形成什么产出，如何即时评价，常见错因怎样处理。情境持续服务核心问题，不能只有“教师讲解，学生回答”的泛化表格。

板书呈现问题、关系、方法、结论及易错点；可以简洁，不只写几个孤立词。课后反思没有实际课堂证据时，写观察重点、预期障碍和调整预案。

## 五列过程表

固定：环节｜教师活动｜学生活动｜任务与评价｜设计意图/二次备课。
不增固定“时间”“PPT页码”列；必要信息自然写进活动或保留内部引用。过程环节按本课决定，不硬套数量。

A4竖版，五列压入正文区，细线、浅色表头、固定列宽、紧凑内边距。正文11pt，表格10.5pt，自然跨页、重复表头。不为凑页数加空白，不强制教学过程另起一页。反思长段用普通段落，避免强塞大表格。

## 输入JSON

`_state/documents/lesson-plan.json`含title、source_versions、page_order及content：

```json
{
  "metadata": [{"heading": "教学目标", "paragraphs": ["依据本课填写完整目标。"]}],
  "rows": [{"page_ids": ["P001"], "cells": ["情境导入", "真实教师组织", "真实学生活动", "任务和评价依据", "具体设计理由"]}],
  "afterword": [{"heading": "板书与教学反思", "paragraphs": ["依据本课写板书结构与课后观察重点。"]}]
}
```

示例只说明字段，不能照搬成最终教案。metadata/rows非空，cells严格五个非空字符串；每行内部page_ids的并集覆盖实际课件，正文不打印这些ID。source_versions包含锁定记录及页图哈希，与另两种文稿一致。

## 自审

检查数学事实、资料追溯、目标活动评价、过程可执行、板书结构、中文显示、DOCX/PDF同源及跨页表格。不能只以章节数或页数判定质量。普通不足直接修订；事实冲突、缺来源、乱码截断等硬问题解决后再交付，不额外要求文稿最终审批。

# 小学数学教学设计

以[四类文档基准](teaching-pack-profile.md)和当前有效课件为依据，教学设计目标为约5000字，以实际Word/WPS字数统计核对。篇幅用于写清核心知识、教学组织、学生活动和必要引导，不靠重复说明凑数。正文规范不调用任何被禁用的K12 Skills。

写作前执行基准中的[课件完成状态核查](teaching-pack-profile.md#制作前先核查ppt是否完成)：先查看PPT和已有依据，无法判断是否完成或采用哪一版时再询问。未完成课件的提前教案须有用户明确要求并标为草稿，不能自动当作成品配套。

## 默认结构顺序

1. 教学基本信息：紧凑表格写课题、学科年级、课型、课时、教学内容、教学方式、实际AI教学用途、教师/学生准备；无依据的项目省略。
2. 教材与学情分析：合并为一个部分，分段写已有学习联系、核心内容、预计困难；区分教材本身与本课原创情境。
3. 教学目标：3—4条具体可观察目标，涵盖知识技能、学习过程、表达应用及适当学习态度；核心素养落到行为，不另堆术语。
4. 教学重点与难点：分别说明必须掌握什么和理解易卡在哪里。
5. 教学过程：五列过程表，作为正文重点；按实际教学环节组织。
6. 板书设计：可实际书写的简洁关系、方法和结论。
7. 作业设计：基础与必要的选做拓展，依本课内容，避免原样重复课堂已完成题。
8. 教学反思与AI赋能说明：无实际反馈写教学预设反思；有AI才说明真实教学功能。

不强制扩为十一栏目。教学准备、教法学法可融入基本信息和过程，不在多个栏目重复同一说明。用户另给模板时按其模板。

## 内容

结合锁定课件写教材/内容分析、学情、目标、重难点、教法学法、准备、教学过程、作业/拓展、板书与反思。未知教材页码、课标原句、班情数据不编造，基本信息里无依据的行省略。

目标、活动、评价对应：学生要理解什么、怎样操作或表达、教师凭什么知道学会了。数学重点写概念形成、例题与变式链、易错点、板演、数学思想和分层支持。

每个关键环节说明教师如何启动问题、追问和组织，学生实际做什么和形成什么产出，如何即时评价，常见错因怎样处理。情境持续服务核心问题，不能只有“教师讲解，学生回答”的泛化表格。

板书呈现问题、关系、方法、结论及易错点；可以简洁，不只写几个孤立词。课后反思没有实际课堂证据时，写观察重点、预期障碍和调整预案。

## 五列过程表

默认：教学环节｜教师活动｜学生活动｜设计意图｜时间。
对应课件页码写在环节名或教师活动中，不再加第六列；评价依据与必要纠错自然融入教师/学生活动，不另设重复的“任务与评价”“二次备课”列。过程环节按本课决定，不硬套样本行数。每个主要环节给出建议时间，合计与课时一致。

A4竖版，五列压入正文区，细线、浅色表头、固定列宽、紧凑内边距。正文11—12pt，表格10.5—11pt，自然跨页、重复表头。不为凑页数加空白，不强制教学过程另起一页。反思长段用普通段落，避免强塞大表格。

## 源稿与旧接口

优先用完整MD/JSON源稿和原生DOCX表格呈现上述八部分与五列。旧接口的列标题固定为另一套栏目，不适用于本默认版式；具体边界见[接口说明](teaching-pack-profile.md#导出格式服从正文用途)。下列JSON仅保留给明确使用旧版格式的任务，不是新教案的固定结构要求。

`_state/documents/lesson-plan.json`含title、source_versions、page_order及content：

```json
{
  "metadata": [{"heading": "教学目标", "paragraphs": ["依据本课填写完整目标。"]}],
  "rows": [{"page_ids": ["P001"], "cells": ["情境导入", "真实教师组织", "真实学生活动", "任务和评价依据", "具体设计理由"]}],
  "afterword": [{"heading": "板书与教学反思", "paragraphs": ["依据本课写板书结构与课后观察重点。"]}]
}
```

示例只说明字段，不能照搬成最终教案。metadata/rows非空，cells严格五个非空字符串；有逐页课件时每行内部page_ids的并集覆盖实际课件，正文不打印这些ID。整课source_versions包含锁定记录及页图哈希，与另两种文稿一致；独立教案只登记实际输入来源，不编不存在的PPT页码或课程记录。

## 自审

检查数学事实、资料追溯、目标活动评价、过程可执行、板书结构、中文显示、DOCX/PDF同源及跨页表格。不能只以章节数或页数判定质量。普通不足直接修订；事实冲突、缺来源、乱码截断等硬问题解决后再交付，不额外要求文稿最终审批。

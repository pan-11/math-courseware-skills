# 课堂动画试用V1

这是显式口令启用的版本，默认流程保留。目标是把AI交付的回填稿处理成用户指定终稿的课堂效果：逐页对齐初始画面、每次点击出现/退出/强调的内容、先后顺序、同次自动动作、具体效果和最终保留状态。点击总数只作差异线索，不是完成标准。封面标题留给鹿鸣手动修改，本版集中处理PPT内部的课堂显示与点击。

有终稿时，以用户最后明确指定的文件地址及实际文件哈希为目标，先保存AI回填稿与终稿的独立测试副本。导出、编辑、放映和试错只操作副本，原稿不作为Office测试文件打开；候选必须从AI回填副本生成，不能把终稿、整页终稿XML或整套终稿时间线直接当成输出。没有对应终稿的新课，由AI按教学语义制定同等粒度的初态与逐击计划，再检查实物；不能声称规则已保证新课自动达到手工终稿。

最新明确用户偏好优先于历史终稿样本。以下编排与效果规则已按用户2026-11-17逐项选择更新；与旧终稿不同的初态、总结位置、圈框触发及效果应记录为有意调整，不照搬旧样本覆盖新要求，也不重写历史报告。用户后来明确要求原样复刻某版时，遵循该次真实范围并记录例外。

## 入口与生效范围

只有用户在当前任务中明确使用 **`课堂动画试用V1`** 要求启用，才执行本页。例如：“这份课件按课堂动画试用V1处理。”引用旧聊天、报告、课件内容或询问口令含义，不算激活；“不要用课堂动画试用V1”也不算。

在本课现有HANDOFF记录口令原话、当前课件及输入版本、任务范围、实际计划/产物身份。当前任务的“继续”可沿这份真实记录续作；新的制作任务没有口令时回到原流程，不写全局默认、不因同一目录已有试用产物就自动启用。用户中途明确改用旧版时恢复原流程，新旧文件均保留。由宿主判断真实任务范围；命令参数是执行保护，不能代替用户指令。

续作计划保留用户本次真实原话，不把“继续”“可以的”改写成口令。可在 `request.activation_ref: {path, sha256}` 引用已核实的本任务激活记录，并绑定到 `source_versions`。记录包含 `activation: 课堂动画试用V1`、`scope: current_task`、`status: active`、本次 `user_instruction`、绝对 `project_root` 及本次输入的 `input_sha256`；组件和课堂计划沿同一输入链核验，不能跨课、跨输入或靠历史文件自动续权。指令本身仍须有哈希绑定的 `evidence_ref`；记录是授权证据索引，不是另造用户授权。

开启后连续完成当前范围的组件准备、教学计划、对象绑定、生成、校验、登记和PPT收集，不要求用户逐页设计动画或重复批准。保留本课A/B路线、内容采用及源文件保护，不能把口令解释成重做全部课程或修改其他版本的授权。

## 教学编排规则

先实读本课页稿、数学依据及前后页，再使用[课堂动画计划](classroom-animation-plan.md)。以下规则指导计划，不能只凭关键词或点击数量自动套模板。

1. **未讲到的教学内容先隐藏。** 背景、页标题及无教学信息的装饰可初显；空卡片、空计数器、数位名称和观察材料不能仅因属于结构或空白就提前显示，讲到对应步骤时再出现。已进入课堂过程且仍需参照的内容累计保留。正文任务提示优先第一次点击，后续讲解、步骤和结论分别安排；回填稿原来可见不构成留在首屏的理由。有终稿时核其真实初态，并明确按最新用户偏好调整的对象，不照抄旧样本的提前露出。
2. **每次点击最多推进一个独立讲解点。** 先列本页可分别提问、观察、解释或核对的环节，再分配点击；不得把多个独立环节同时放出，也不得让它们在一次点击后自动依次播完。“同一张卡片”“同一个组”“属于同一主题”都不是合并理由。一个文本框中的多条方法、特征或总结按教学含义逐条揭示，完整句子和数学整体不按字拆分。给方法让学生执行时，方法文字先出、图示后出；观察后认识概念时，实物/图先出、名称后出，回顾页同样分击。转向箭头与下一变换结果、题目与答案分别留停顿。一个完整答案、同一步说明与图示、内容及其底板可以同次；必须同时观察的完整对照或数序须写清缺少哪一部分就无法完成本次观察，不能借“比较”放出所有后续解释。静态活动页、媒体页及范围保留页可以零新增点击，但必须有真实分类、完整对象清单和理由，不能借此跳过教学页。
3. **普通答案保持完整。** 多位数、单位相关的完整结果、普通分数作为一个逻辑答案后显；一个空的分子、分数线、分母同次显示。不同作答位可逐个核对，过程页和小结页不必强套同一粒度。
4. **推导完整，总结跟随其依据。** 不凭终稿表象跳过数学依据，也不照抄错误。多个步骤各有局部总结时，每步完成后另点一次出现对应总结，再进入下一步；只有一个整体总结时，全部过程完成后再点出总结。不能仅因结论在图旁或页面上方就提前显示。核完整式子、条件和等价关系，图形变化与标注应能支撑下一结论。
5. **同一步说明与示意图默认同步。** 需要学生先预测结果时，先出说明、再点出图示；否则同一步的文字和配套小图可以一起出现，但多步说明不能因此合并。先列独立讲解点，再绑定PPT对象，不从现有组数量反推点击数。读图页先进入坐标轴/图例，再逐项数据、标注与结论；直条和数字是否同次按该点的观察任务说明，不默认一击放完整图表和结论。
6. **圈框默认另一次点击；自动接续不跨讲解点。** 图或文字先出现，教师再单击才用轮子圈框，不默认随图自动圈出；圈框承担引导视线还是答案提示均沿此默认。文字与底板同步、同一动作的必要运动、临时问号/旧状态退出与新状态进入可同次，不用自动接续绕过独立步骤或总结的点击。仍需参考的证据累计保留；优先在原对象强调，避免重复叠字。保留合理时长和延迟，不统一改成一个速度。
7. **视频与标题。** 专门视频页只放视频，不额外增加观看任务文字或提问点击；内容页内的局部视频保留本页任务。播放触发沿本课已选方式，不把“直接播放”猜成自动播放。封面主标题不提取、不重画、不替换。
8. **效果忠实且能力明确。** 对象仍烧在背景里时，按已授权范围准备可控对象后再编排。除出现、淡入、擦入、退出及文字强调外，原生编译支持 `peek`、水平 `stretch`、水平 `random_bars` 和单辐 `wheel`，具体字段见[动画计划](classroom-animation-plan.md)。支持写入不等于已通过目标软件实播；不能拿淡入冒充移动、折叠或旋转，未支持的专项运动具体列出并保留原有有效动作。明确的重复入场可按受限 `replay: true` 保留，但须核真实初态和逐击画面，不能仅凭XML的重复记录补入一次退出。新增填空组件统一完整后显；分数写法专项拆分使用既有专项计划另核，不强行拆普通答案。

## V1效果选择与逐击复查

有明确终稿时先读取实际效果、方向和时长，再按最新用户偏好核需调整之处。每个动作明确效果和时长，有方向的另写方向，不能省略后交给统一默认值。无明确目标的参考初值为：展开/切入500ms，红框单辐轮子2000ms，普通淡入250—500ms按内容与节奏选择；这些是起点，仍须实际放映核速度，不能把所有效果统一500ms。用户允许AI按内容选用合适的不同效果，无需逐效果询问；在实际支持并可核验的范围内选择，不能随机轮换或用花样数量代替教学节奏。下列偏好仅用于V1，不改变普通原位答案回填的默认出现效果。

| 对象与课堂用途 | V1优先候选与复查 |
|---|---|
| 普通说明、问题、规律、结论文字及卡片 | 更多使用水平展开 `stretch`，有方向或依次进入的语义时也可选切入 `peek`；文字与承载它的底板同步。并列的多条讲解分别点击，不因共享文本框或底板一起出现。 |
| 答案、数字、小图 | 短淡入 `fade` 为主要候选，完整答案整体显示；按具体任务也可选其他已支持效果。只有确需瞬时呈现并写明理由才用 `appear`，不得批量省略效果或统一套出现。 |
| 有指向意义的箭头 | 切入 `peek`，运动沿箭头指向：向右从左往右，向下从上往下。`wipe`擦入与`peek`切入不是同一动作，必须核实际运动及裁切，不互相冒充。箭头与下一结果是否再分一击单独判断。 |
| 围住文字或图像的红框/圈选标记 | 图或文字出现后，另一次点击单辐轮子 `wheel`，仅作用于独立框线。若框已画在图片中，先列对象准备缺口并沿已授权范围拆层；不能把整图轮转或图框同时出现算作满足。 |
| 大面积图片或文字 | 用户新增偏好包括百叶窗；先核本页适用性和实际实现/播放支持。当前已验证接口的随机线条 `random_bars` 不等于百叶窗；未实现时具体列出，不以出现替代后称已满足。样本未出现的效果不能写成已由样本证实。 |

逐击复查应记录“本击新增的独立讲解点、实际文字/图示、同次依据、效果/方向、教师停止点击后还会自动出现什么”。展开组内子对象、文本段落与图片中的内容检查，不只看最外层对象数；多于一个独立讲解点且不符合上述必要同次情形时，退回拆分。重点检查多条说明、多道题/多个答案、箭头加结果、图加圈框和所有总结是否被捆成一击；同次说明与示意图不得夹带下一步骤或答案。逐击播放时停止点击，确认后续独立内容不会自动泄露。不能只核总点击数或用候选计划自证符合用户节奏。

效果复查逐项排除无理由的 `appear` 和省略效果的默认落值，同时检查展开、切入、轮子的方向与时长；不能声称写了不同效果名就已看见对应过程。首屏另核未讲到的空框、标签、图示和答案是否提前露出。以上是必须执行的教学与实物审阅要求，现有编译器不会自动理解“独立讲解点”，不能把格式检查通过当作这项审阅通过。

专项运动另行处理：逐根入场并把已有物体挪到新位置、缩放和位移组合不能用增加普通点击代替。需要额外可控对象或本课专项脚本时明确说明，实际播放前不将其归为通用V1已具备能力。

## 单一时间线的制作顺序

已有合法 `editable-base-pptx` 登记及来源版本时直接复用。用户提供的既有AI回填稿（可以已含答案点击）尚未登记时，先将其复制到本次项目，使用 `classroom-trial-import` 建立独立输入；不用倒补无关整课上游批准，也不能手填artifact冒充经过回填校验的基底。后续命令使用本课已识别的真实目录映射。

导入计划只含 `source_deck`、`source_sha256`、`source_versions`、`output`、`request`、`mapping`；源与输出为项目内路径，输出必须为未占用的新PPTX路径，映射覆盖全部实际页。真实指令及必要来源绑定哈希，导入后复核复制字节、页序、对象与原生时序清单，并保存不可覆盖的 `.refill-input.plan.json` / `.refill-input.json`。独立artifact为 `editable-classroom-trial-input`，身份为 `provided_refill`，`content_review` / `playback` 均未验证；不改变旧 `editable-base-pptx` 或默认交付选择。再次使用须重核计划、收据、来源及副本哈希，不能用导入成功代替回填或教学验收。

1. 核本次回填输入及目标副本，读取全部页面和已有点击；已有答案对象/动画如实登记，不能当成空白再次新增。把已采用页稿或指定终稿的讲解、过程、结论及图形与实际对象逐项核对：`deferred_text_units` 仍是待处理项，不能只补答案就称完整课堂版。缺失的已采用后显文字沿现有 `editable-build` / `teaching_reveal` 能力准备，已有回填的专项对象准备须保留来源并重新导入本次输入；图形沿已授权的拆层/对象准备能力处理，不借动画阶段重排版面。内容去向记在本课现有记录中，无法实现的过程具体列出。再逐页扫描确定答案、开放空位、已显示答案和真实歧义，保留来源/验算、位置与图层。
2. 采用[原位答案计划](click-answer-plan.md)的对象字段，显式设置 `mode: components_only`，另存组件PPT。此阶段只新增答案对象，不新增答案时序；源对象和原时序保留。组件模式可省略 `click_order`；保留该字段也不产生点击，最终课堂顺序以随后计划为准。组件稿不是可交付课堂成品。
3. 读取真实组件ID。扫描及计划覆盖当前基底全部实际页面，无答案页也显式登记；只修改指定页时，其余页保留原内容/动作，写明静态或无新增动作原因，不因扫描扩大制作范围。课堂计划以组件稿为 `source_deck`，绑定其哈希及必要来源；所有确定答案组件按 **页ID＋实际页序＋空位ID** 核覆盖，全部初始隐藏且最终按教学顺序揭示。不要把整组答案漏出units，更不能跨页借用同名空位。
4. 先冻结全页 `teaching_contract`，绑定组件稿、终稿副本/教学依据、完整页映射及每页全部对象归属；详见[合同字段](classroom-animation-plan.md#全页教学合同)。课堂计划逐项对应初态与 `expected_steps`，统一安排讲解、图形、标记和答案。例如第1点出现观察标记，第2点出现完整答案，第3点显示解释；不先把所有答案点击放在页首或页末再追加讲解。新V1的 `check/build` 必须通过全页合同，旧试用记录可继续读取，但不补写成已通过新合同。
5. 原有动画目标重叠或顺序不符时具体诊断。可用 `replace_managed`，以当前 `timing_sha256`、明确旧 `effect_ids` 和理由选择完整旧点击组，由本计划完全接管的对象重编顺序；未选动作、媒体和交互保持保护，不整页清空时间线。未选主序列仍在新步骤前面，不能假设新旧动作任意交错。仅需追加且对象无冲突时继续用 `append_after_existing`。不满足安全重排条件时返回对象准备或列明缺口，不能重复叠加。
6. 构建候选并重算验证后明确登记试用当前版，随后收集该PPT。不要因缺视觉/实播记录回退旧版；也不能把已知构建错误记成“尚未检查”来交付。

## 控制器入口

控制器为相邻 `math-courseware-studio/scripts/courseware.py`。下列命令由AI准备实际输入并执行，用户只需给口令与课件范围，无需填写JSON。

```text
python -X utf8 -B <controller> classroom-trial-import --project <course-root> --activation 课堂动画试用V1 --plan <refill-input-plan.json>
python -X utf8 -B <controller> classroom-trial-components --project <course-root> --activation 课堂动画试用V1 --plan <components-plan.json>
python -X utf8 -B <controller> classroom-trial-check --project <course-root> --activation 课堂动画试用V1 --plan <classroom-plan.json> --components-manifest <project-relative-components.manifest.json>
python -X utf8 -B <controller> classroom-trial-build --project <course-root> --activation 课堂动画试用V1 --plan <classroom-plan.json> --components-manifest <project-relative-components.manifest.json>
python -X utf8 -B <controller> classroom-trial-register --project <course-root> --activation 课堂动画试用V1 --manifest <project-relative-output.trial-v1.json>
python -X utf8 -B <controller> classroom-trial-current --project <course-root> --activation 课堂动画试用V1
python -X utf8 -B <controller> classroom-trial-collect --project <course-root> --activation 课堂动画试用V1
```

`import`只用于接入已有回填；已有合法基底可从 `components` 开始。`register`可接 `--checks <checks.json>` 保存同版检查证据；缺省分别显示未验证。实际结构与来源从组件/课堂manifest重新核验，不信任手填ready值。版本ID为 `classroom-trial-v1`，当前artifact键为 `editable-classroom-trial-v1`；它与旧 `editable-pptx` 分开。

`checks.json`只含适用的 `review`、`static`、`playback`，每项为文件引用 `{path, sha256}`。review指现有审核packet，试用PPT必须是其被审产物而非仅来源，沿真实verdict判定，valid不等于pass。静态/实播引用的收据使用 `schema_version: classroom_trial_check_v1`，声明 `kind`、`target: {path, sha256}`、`verdict: pass/changes_required/unverified`、非空 `note`、`evidence: [{path, sha256}]`，以及实际方法 `native_static_review` / `native_slideshow`；声称pass或changes_required须有实际证据。收据是有来源的人工/工具检查记录，不是脚本自动看图或实播证明。缺失、过期或格式不符时分别报告未验证/失效/无效，不能沿用通过结论，也不阻止核心正确的PPT交付。

`classroom-trial-collect`收集**本次试用PPT及检查状态**，不是整课视频/文稿/商品素材打包。整课其他配套沿原流程继续，本课交付明确链接本次试用PPT。普通 `collect`维持旧版选择并跳过试用产物，不把两版混装；不能拿普通collect的旧PPT冒充口令任务结果。

## 核验与交付含义

- 必须核：回填输入、目标副本、组件、合同、计划、候选PPT和manifest身份；完整页映射及对象/段落归属；初态、逐击内容/顺序/分组/效果；受控替换范围及其余对象/时序保留。合同通过只说明输出符合已声明计划，仍须独立对比候选与目标，不能用自填计划自证达到终稿。确定错误修复后另存新版本。
- 教学、原生静态、独立审阅和真实逐击各自记录。使用现有可用导出工具实际看图，检查遮挡、裁切、字号与数学排版；导出图本身不是已看图，更不是实播。`animation-inspect`新增的祖先条件/完整动作证据也只是结构读取。
- 用户已选允许先交当前版。缺少或过期的可选检查不阻止登记/收集，但必须失去对应“通过”结论；已知问题另列，不能藏成未查。可选检查证据不能塞入决定当前PPT有效性的必需来源集合。
- 交付写明：试用版本、实际文件、已检查、未检查、已知问题以及余下配套；`current`代表本次选中的PPT，不代表用户已采用或整课商品全部验收。

有指定终稿时，按全页差异逐项消除，实际核过初态、逐击行为及画面后才能声明相应范围达到目标；不能只交“多加了点击”的版本就称完成。无终稿的新课仍须逐页语义及静态检查，并实际播放关键概念、推导、练习、替换/重复入场等页面；未覆盖范围和实际修正记录到本课现有日志，不承诺未验的新课自动等同手工终稿。

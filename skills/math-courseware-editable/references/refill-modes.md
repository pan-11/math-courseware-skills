# 默认回填组合与底层模式

新任务默认交付**忠实复原＋原位填空答案逐个点击出现**。已获授权的整套回填或“忠实复原”请求，未限定无答案时直接执行这个组合，不再询问是否补答案、是否做点击动画或另选样页。明确要求“纯复原”“保留空白”“不加答案”“无答案学生版”或限定页面时，按实际要求执行。仅修错字、字体或指定对象的局部校正不因此扩大为答案制作。

这个交付默认独立于A/B拆层路线、`build_scope`和展示导出，不代替路线选择或制作授权。它只增加已有作答位的确定答案，不自动启用全部教师讲解、图示移动、步骤替换等完整`teaching_reveal`。已有明确范围沿用；已交课件不因默认值变化而重做、迁移或改写采用记录。

## 默认组合的执行

1. 先用`faithful_restore`完成全套基础文字，恢复原位置、字号、颜色、换行、题干、图示和原图层；初始画面保持原作答位空白。参考图本来就显示的例题答案照常复原，不因为其角色是answer而改为隐藏，也不重复添加。
2. 逐页定位真实方框、括号、横线、算式空格及表格作答格，只补有可靠答案来源或可独立验算的确定答案。核对已采用答案、数学记录和题意，记录来源或推导。开放讨论、个人表达、答案不唯一而未指定示例的题目不强填；有歧义的具体空位列入待核，其余已确定内容继续完成。
3. 在原空位上添加独立可编辑答案对象，复用现有题干、运算符和单位，不新增整条重复算式或答案底板。每个空位一个逻辑答案；多位数不能拆成多次单击，分数的分子/线/分母等组件要作为同一次点击显示的答案组，保留数学排版。
4. 答案默认深红色`B3261E`，字号、字形和位置匹配原空位。若与题干同色或对比不足，改用统一且清晰区分的高对比色并记录实际值；用户指定颜色优先。不自动缩字塞框。
5. AI使用当前可用Office工具实际设置原生入口动画，默认`appear`＋`onClick`：放映初始隐藏新增答案，每次单击出现一个逻辑答案，前面答案持续保留。优先沿用已确认的教学顺序；没有指定时按阅读顺序，分解/中间计算先于总结果。保留已有动画与翻页安排，不能清空原时间线或让所有答案同次出现。

基础文字与答案动画分开记录、连续制作，整套完成后一起交付。另存`inline-answer-plan.json`，逐项记录页ID、空位ID/位置、题干或原对象、答案文字、来源/验算、实际对象ID、字体颜色和点击序号；同时保留未处理空位及原因。记录本次制作原话、当前默认规则版本和源PPT哈希，不能编造用户另说过“同意补答案”或看过未来效果。只有明确要求额外教学后显时才扩大范围。

当前`editable-build`只完成基础文字和对象映射，**没有内置上述答案动画阶段**。此组合是宿主工作流，不能把它写成新的`refill_mode`枚举或虚构CLI参数；底层缺省仍为`faithful_restore`以保留旧计划兼容。其`teaching_animation:not_requested`只描述该基础计划，不表示默认组合已全部完成。随后由AI用已有工具在新副本完成答案和动画，并登记最终版本及检查。工具确实不能完成时，交具体页/空位/答案/次序和人工操作要求，明确待完成，不能默认把所有动画甩给用户或把静态答案当作已实现点击效果。

## 底层文字模式与版式

| 模式 | 应写入的内容 | 画面要求 |
|---|---|---|
| `faithful_restore` 忠实复原基础 | 参考带字图实际可见的文字 | 恢复原位置、字号、颜色、换行与层级；基础阶段保持原空白，默认交付再执行上述原位答案动画；明确纯复原或无答案版则只交基础 |
| `teaching_reveal` 教学后显 | 原图可见文字＋本次范围内已确认的后显文字 | 初始画面沿用复原基础；填空/表格在原空白处出现可区分颜色的答案，共用题干/算式；整段替换须有明确的先隐后显安排，不能叠放后宣称完成 |

两种模式共用正确文字、原图层保护和可编辑数学对象要求。文字内容以核对后的定稿为准，原图错字/错式须记录纠正；视觉依据仍为对应已确认带字图。尊重已确认字体约定，无约定时匹配参考图可用字体并说明限制。分数可用独立分子、横线、分母组合，不能为省事改成斜杠字符串或扁平图片。结构验证不证明字体或视觉完全一致。

制作前逐页核对带字图与定稿：`text_units[].visible_at`为`initial`或真实`reveal_steps[].step_id`；未标注且不属于任何后显步骤的旧单元按初始文字处理，不凭`role:answer`猜测隐藏。后显步骤可补足未写visible_at的归属；两者冲突、未知步骤或重复归属须先纠正来源。原图与标注不一致时报告具体差异，通过正常来源修订解决，不在执行计划中偷偷把初始文字改成后显以绕过覆盖检查。

忠实复原基础必须覆盖全部适用页的初始单元；基础阶段未写入的后显单元自动列入报告`deferred_text_units`，保留原文、页ID和出现步骤，不从权威页稿删除，也不误报为漏填。默认答案阶段引用其中实际适用的填空答案时，在最终交付映射中登记已实现的对应项及仍延后的讲解/图示，不篡改基础报告或把未实现的全部步骤标为完成。完整教学后显覆盖所选页全部已确认单元。任一模式都拒绝多字、漏字、错字或重复逻辑单元。图形独立性要求按相同可见范围检查；未标注可见性的图形要求仍保留，不能凭猜测豁免。

## 计划与选择证据

沿现有回填计划增加可选字段，不增加新的采用轮次：

```json
{
  "refill_mode": "faithful_restore",
  "page_modes": {"P009": "teaching_reveal"}
}
```

`page_modes`仅覆盖映射中的页面，其余继承`refill_mode`；底层文字计划缺省为忠实复原基础，默认交付组合另有原位答案计划。不得使用未知模式或未知页。执行报告记录全部页的有效模式、初始/写入/延后单元和真实参考图版本，便于续作；模式不是A/B路线选择。

有任一教学后显页时，现有`authorization`证据除源哈希、页范围、用户原话外，还须有`refill_modes`，逐页等于本次有效模式。复用已存在的真实选择，不要求用户重新确认。历史`review`仍可绑定包含明确模式的完整计划；不能用未选择教学后显的通用整套授权代替。不得倒填用户看过未来效果。

复原版和增强版使用不同输出路径，保留原件及复原依据；原来已经校准的复原文件可以复用，不强制每次另造一份。既有输出的计划哈希和文件哈希未变时只返回原结果；没有模式字段的历史成品不追溯重标或重建，也不以当前来源刷新其旧登记。重新修改旧课时根据真实指令写明模式，保存新计划/版本，禁止覆盖用户手调文件。

## 共用文字与原位填空

已有`segments`仍须按序拼回完整权威文字。教学后显可让某些片段引用同页已规划的初始文字对象，只新建答案片段：

```json
{
  "page_id": "P009", "unit_id": "answer", "text": "40/100＝40%",
  "segments": [
    {"reuse_object_id": "fraction-and-equals", "text": "40/100＝"},
    {"object_id": "answer-number", "text": "40", "box": {"x": 300, "y": 180, "width": 80, "height": 48}, "font": {"color": "B45309"}},
    {"reuse_object_id": "percent-sign", "text": "%"}
  ]
}
```

这里`fraction-and-equals`/`percent-sign`必须实际存在于同页初始单元的计划中，片段原文必须一致；它们可以来自普通单元或已拆分单元。引用不创建第二个文本对象，不重复播放题干。不能引用不存在的对象、另一页对象、另一个后显对象或形成引用链。参考分数在正式PPT中的分子/线/分母布局仍须另按数学对象规范实现，上例文字仅说明逻辑对应。

执行器生成文字和对象复用映射后，AI继续用现有工具完成本次范围内的原生动画；完整教学后显还须核替换、先隐后显等实际动作。制作与播放验证分别记录，工具限制按具体页交接，不能把文字已生成或模式已登记说成课堂后显已经完成。

## 展示导出与验收

展示导出是独立用途。纯复原核验后可按原页直接导图；默认含答案动画版和完整教学后显版按真实教学状态另存静态展示PPT/PNG/PDF，保持课堂版页序与步骤映射。教学步骤预览覆盖初始及各次答案状态；可以另交明确标注的含全部答案静态核对稿，但不能把它当作初始画面、步骤展示或动画验收，也不为满足导图偷偷改课堂节奏。

默认组合验收逐页对照原带字图核基础文字/版式，另逐空实算答案、核原位/异色/可编辑性、真实原生单击目标与顺序、初始隐藏和每次仅新增一个逻辑答案及累计保留；完整教学后显另核全部已选步骤和替换动作。编辑界面显示全部入口动画答案通常正常，不能因此删除答案或误称放映会提前显示。

课堂播放、编辑界面、静态导出分别记录实际检查范围。原生时间线读回与静态状态图可验证结构和布局，不能替代实际单击播放；已有同版有效播放记录或用户实测反馈沿用。原件/旧版哈希、未处理图形、未实际播放等限制照实保留，实放缺证据标未验证，结构通过不能代替动画或整课验收。无适用填空时记录零项并交忠实复原结果，不凭空出题。

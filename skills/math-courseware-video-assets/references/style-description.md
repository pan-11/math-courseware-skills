# 从采用彩色资产提炼固定风格

本规范由图片资产模块负责：第2步形成有实际图片依据的初稿，第5步从当前采用来源冻结视频各片段逐字共用的一段风格描述。它延续已有视觉，不重新设计项目画风。

## 输入与判断

实际打开已采用的角色图、场景图和主要道具图，记录文件、用途、版本、SHA256、查看结论及采用依据。不要只看文件名、提示词或黑白故事板就宣布已提炼画风。只有文字说明或未采用彩色图时可以写候选，不能标为由已采用实图冻结。

只把图上能够支持的特征写成既定描述：

| 维度 | 从图片观察什么 |
|---|---|
| 视觉媒介 | 二维插画、剪纸、水彩、三维动画、定格质感、写实等，不混写不相容风格 |
| 角色与形体 | 头身比例、轮廓、边缘、服装材质；具体身份交给角色参考，不在风格段重画人物 |
| 色彩 | 主辅色关系、饱和度、冷暖和明暗层级，不从黑白板推断配色 |
| 光影 | 主光方向、软硬、时间/天气、阴影和环境光；不同剧情时段允许有依据的局部变化 |
| 材质与细节 | 平涂、笔触、纸纹、柔软或硬质表面、细节密度，避免空泛“8K、顶级、昂贵” |
| 空间与清晰度 | 背景层次、透视、景深和主体分离，兼容前后镜头 |

运动节奏和人物表演从已定剧本/导演表继承。单张图片不能证明帧率、运动模糊或动画流畅度；这些不能伪装成风格观察。

## style.md的固定结构

1. **状态与版本**：标明初稿、候选或已冻结，记录适用视频版本及依据。冻结不等于新图片自动被用户采用。
2. **来源表**：资产ID、实际文件、用途、版本、SHA256、查看结论、采用状态和真实依据。
3. **一致性检查**：说明哪些图一致；有冲突时指明具体文件与差异。已有明确选定视觉优先；两个采用来源冲突且影响制作时列出需决定的具体取舍，不能未经授权“融合”成第三种风格。
4. **固定段落**：视觉媒介→形体与材质→色彩与光影→空间层次→跨段一致性，形成一段可直接复制的完整中文。无需写死字数、画风或景深。
5. **允许的局部变化**：写明有剧本依据的白天/夜晚、地点光照变化，保持角色设计、材质语言和总体表现方式，不把夜景强行改为白天。
6. **冻结依据与继续**：记录段落依赖的真实来源版本与哈希；冻结后各生成片段逐字复用。来源变化时先判断影响，再修订版本，不仅刷新哈希掩盖内容变化。

第5步核对导演与实际黑白板是否仍使用上述彩色资产、人物和地点。黑白板用于验证构图与顺序，不能取代彩色来源或决定配色。与第2步实图及采用依据完全相同且段落已适用时直接沿用，不另造新风格审阅节点。

## 段落示例（不是默认风格）

以下假设真实采用图已经确认是二维水彩纸感：

> 全片沿用已采用参考图的二维水彩插画表现。角色轮廓柔和，保留手绘边缘与轻微纸张纹理，物体以简洁色块和浅层水彩晕染表现。色彩温暖清透，明暗过渡柔和，主体与背景通过色值和空间层次区分。各片段保持同样的线条、纸感、角色比例与细节密度；具体场景的时间与光照按已定镜头安排。

其他项目可以是三维动画、剪纸或写实，必须依据本次实际图片提炼，不继承上个项目示例。提示词模块逐段复制固定段落原文，不能在组装时润色成不同画风。

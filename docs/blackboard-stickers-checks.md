# 电子黑板贴稳定制作接入检查

2026-09-24，用户认可最终混合字体与留白版，并明确选择“默认作为配套一起制作”。本次保留十二模块，将黑板贴接入C7配套文稿，C8核实际交付。独立制作只核指定课件，不补造其他阶段或强制三份文稿。

## 实施

- [制作规范](../skills/math-courseware-documents/references/blackboard-stickers.md)：AI从定稿课件选择教学内容、来源、形状和板书组织；固定A短词/B说明/C读法字体、描边、标签内距及中文普通目录交付，数量不绑定某一课。
- [程序](../skills/math-courseware-studio/scripts/runtime/blackboard.py)：source-bound spec、字体/缺字预检、真实字形轮廓安全区、透明PNG、独立图片对象PPT、布局PDF、离线总览及文件/来源检查。旧版本拒绝覆盖。
- 三款开源字体按原许可随包保存，系统字体仅定位读取。fontTools用于检查字形覆盖；渲染与Office导出可分别使用已有运行时，无全局安装。
- 单独新增黑板贴CLI，没有伪造courseware.py子命令。当前collect/complete仍不自动收集/检查黑板贴，由C8按专门manifest补做核对；这一边界写入总入口、共用流程和制作规范。

## 实际边界

像素一致证明已认可文字样式可复现，不保证任何新布局自动美观，仍须逐板视觉核查。来源哈希证明使用哪份资料，不替代教学判断。简单整数连加/连乘等式可自动验算，其他数学需另核。PPT素材为可移动PNG，字形不是原生可改字文字；PDF为整板布局参考。WPS静态导出未替代课堂硬件投屏和远距离识读。
